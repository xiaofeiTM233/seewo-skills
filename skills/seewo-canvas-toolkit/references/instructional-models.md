## 1. 先定层级：课题 → 课时 → 用途 → 环节

画布支持按需读取详情与内容。分类依据实际确认的主题、用途和材料关系，不是补全教学设计；名称不足时先补读，读取失败须保留边界。判断顺序固定：

1. 老师要求（“按课题分”“按文件类型分”）优先，覆盖其余规则。
2. 先定唯一维度：多个课题 → 用课题名分区；单个课题但课时清楚、各自成套 → 用课时名分区，跨课时的单元/整课材料单列“整课材料”；单个课题单课时 → 用用途/环节分区。同一张画布不混用维度。
3. 同一课题、课时内，内容或名称能确认用途（导入、检测、量规）才按环节分。依据不足时先按需补读。
4. 整张重整使用 `arrangeable:true` 的节点。用途仍不明确时优先沿用已有分类，散落材料可归待确认或交由 SDK 归入「未分类」。

这条顺序与后文的框架是“容器与内容”的关系：框架只在同一课题内部决定材料怎么摆。

**命名与孤立项规则**

- 分区名只写分类本身：`情境导入`、`整课材料`、`学习活动`、`荷花`、`第一课时`，不写 `观沧海 · 情境导入` 这类复合名，也不加序号、括号注释。分区名在同一张画布内唯一。
- 维度由材料结构决定，不由学科或课型推定：两种维度同时可用时选更粗的那一个（先课题、再课时、最后环节），保证标题短、不重复。
- 无主题线索的图片和未命名文档先按需读取内容，再按上述规则处理不明确的归属。用途明确的材料即使只有一个，也可按实际用途成区。

## 2. BOPPPS

**定位**：常规课堂、微课、公开课、赛课、教师培训等结构完整的教学材料；国内最常用的一体化课堂框架。

**分区骨架**：情境导入｜学习目标｜学情检查｜学习活动｜练习与检测（含达标评价）｜总结拓展。前测/后测不明时把“练习”并入本区，总数压在六个以内。

| 环节                     | 收什么                               | 名称线索                     |
| ------------------------ | ------------------------------------ | ---------------------------- |
| 导入 Bridge-in           | 情境、问题、现象的引入材料           | 情境导入、视频、图片激趣     |
| 目标 Objective           | 学生能做到什么、成功标准             | 教学目标、学习目标、素养要求 |
| 前测 Pre-assessment      | 课前诊断、经验调查、已有知识检测     | 学情、前测、问卷、预习单     |
| 参与式学习 Participatory | 讨论、操作、探究、任务单、示例与支架 | 活动、任务单、探究、讨论     |
| 后测 Post-assessment     | 当堂检测、达标任务、评价量规         | 检测、达标、随堂测、量规     |
| 总结 Summary             | 归纳、反思、回扣目标、连接后续学习   | 小结、总结、思维导图、反思   |

**归类要点**：前测/后测不明的“练习”进“练习与检测”，不猜时点；完整教案不能因含目标就整体放进“学习目标”；只建有材料的区，不要求每节课凑齐六个文件。

**局限**：固定环节骨架会压平探究课与项目课；六区全建时画布偏拥挤，材料少时应合并。

**追问话术**：BOPPPS 关注目标、学生参与和学习检查，用它组织能直接看出每个环节有没有对应的检测。

## 3. 5E 探究

**定位**：明确的探究任务——科学、物理、化学、生物、小学数学等，名称出现问题、实验、观察记录、解释。

**分区骨架**：问题情境｜探索与取证｜解释与建构｜应用拓展｜评价反思。

- 问题情境（Engage）：值得探究的问题或现象，唤起已有认识。
- 探索与取证（Explore）：观察、操作、实验、收集与比较证据；实验任务单、记录表。
- 解释与建构（Explain）：基于证据提出解释、澄清概念、建模；不只是公布答案。
- 应用拓展（Elaborate）：把认识用于新问题、新情境；迁移任务。
- 评价反思（Evaluate）：学生表现、自评互评、教师反馈，可贯穿过程。

**归类要点**：老师指定探究课，或名称明确体现探究活动时才用；不因属于理科就套用；不强行凑齐五环。

**局限**：纯讲授、复习、习题课不需要五环，套用后“解释与建构”区往往空转。

**追问话术**：5E 让学生先动手取证再形成解释，最后迁移，符合科学课的探究进阶。

## 4. UbD 逆向设计

**定位**：老师已给出目标、作品任务或评价量规，或需要对“教—学—评”是否对齐做诊断时使用。

**分区骨架**：学习目标｜达成证据｜学习活动。

**三个核心问题**

1. 预期结果：学生最终理解什么、能完成什么任务、把所学用于什么新情境。
2. 评估证据：用什么作品、表现任务、检测或量规证明学会了；“做过活动”不等于学会。
3. 学习活动：支持目标与评价任务的学习、练习与反馈材料。

**归类要点**：只采用老师已说明的目标，不凭课题名称编造课标要求；不能声称已核验材料内容与目标匹配度；没有明确目标时退回按主题、用途归类，不硬套三个区。

**局限**：它是备课设计逻辑，不是课堂播放顺序；单看名称通常无法确认真实目标。

**追问话术**：逆向设计先想清楚“学会什么、怎样证明学会”，再安排活动，所以目标和评价材料要独立可见。

## 5. 大单元 / 项目式（UbD + PBL）

**定位**：跨课时、有单元主题、驱动问题、项目书或成果作品的材料。

**分区骨架**：单元主题与情境｜驱动任务｜学习资源｜成果与评价。

- UbD 提供单元层面的“预期结果—评估证据—学习活动”逆向设计；
- PBL 提供“真实情境—驱动问题—持续探究—公开成果”的项目结构。

**归类要点**：单元规划页、教材单元 → 主题与情境；任务单、项目书、驱动问题 → 驱动任务；资料包、工具 → 学习资源；量规、作品要求、展示方案 → 成果与评价。

**局限**：只有单课时材料时用它显得空旷；没有成果或量规时如实说明证据缺失，不虚构。

**追问话术**：大单元先立主题与情境，再用驱动任务串起课时，成果与量规单列，便于检查是否都指向同一单元目标。

## 6. 备课材料框架（ADDIE）

**定位**：画布是一堆还没成课的备课文档——教材、课标、学情、目标、活动设计、练习混放。

**分区骨架**：教材与课标｜学情分析｜教学目标与重难点｜教学活动｜练习与评价｜素材资源。

- ADDIE：Analysis 分析 → Design 设计 → Development 开发 → Implementation 实施 → Evaluation 评价。
- 把“练习与评价”独立成区（与逆向设计一致），避免所有材料都堆进“教学活动”。

**归类要点**：归不到环节的图片、视频、链接才进“素材资源”；能判断环节归属的素材按环节归组。

**局限**：备课视角，不体现课堂时间顺序；同一份活动设计可能横跨多个环节。

**追问话术**：按 ADDIE 的备课链条组织，先教材与学情、再目标、再活动、最后评价，备课资料不会散成一堆。

## 7. 布鲁姆认知层级（修订版）

**定位**：习题、试题、任务单居多，或需要体现难度梯度。

**分区骨架**：记忆与理解｜应用与分析｜评价与创造。

- 记忆：识记、背诵、概念复述；理解：解释、举例、比较、概括
- 应用：计算、作图、用于新情境；分析：拆解、归因、对比实验
- 评价：依据标准评判、给出反馈；创造：设计、方案、作品、建模

**归类要点**：只凭名称常判不准层级（“练习一”可能是应用也可能是记忆）；先补读题目、任务与评价要求，仍判不准归待确认，不用猜测填满认知层级。

**局限**：不体现课堂顺序；难度不等于层级，题量大也不等于高阶。

**追问话术**：按认知层级由低到高组织，能看出练习是否覆盖到高阶任务，而不只是记忆复现。

## 8. 分层差异化（三层任务 + UDL）

**定位**：名称出现基础、提升、拓展、必做、选做、A 层、B 层，或明显是同一知识点的多难度材料。

**分区骨架**：基础巩固｜能力提升｜拓展挑战｜学习支架。

- 三层任务：面向全体、面向大多数、面向学有余力；
- UDL（通用学习设计）：支架要单独可见——图示、范例、步骤卡、词汇表、提示单。

**归类要点**：分层是同一目标的不同路径，不是把难题和简单题随便分堆；名称看不出目标时说明依据有限。

**追问话术**：按“基础—提升—拓展”加支架区组织，既看得出分层，也看得出给谁搭了什么脚手架。

## 9. 资源类型兜底、整课材料与未分组材料

- **按资源类型兜底**：课件｜教案学案｜图片素材｜音视频｜链接。老师明确要求按类型或只需盘点时使用；内容判断失败的材料归待确认，不把类型兜底冒充教学分析。不能因是视频就判为导入、因是文档就判为练习。
- **整课材料 / 教师参考**：完整课件、完整教案覆盖多个环节，单独成区，不硬塞进某一环节，也不拆分容器。
- **未分组材料**：散落材料和顶层「未分类」的成员可留给 SDK 归入「未分类」。已有分类的独立材料须明确提交目标分类。整理后按实际回执说明未分组数量和原因。

## 10. 组合规则、课型对照、常见误区与解释话术

**只用一个主框架**。可以借用第二个框架的一个区（如 BOPPPS + 一个“分层作业”区），但不要两套骨架混排，否则分区语义互相冲突。

**分区尽量一一对应分类**：默认一个分区只写一个分类，不出现“目标与学情”这类复合标题；只有分区超过六个时才合并相邻的次要环节，用“与”连接两类真实存在、都有材料的分类。

**课型对照**

| 课型        | 首选框架           | 备选         |
| ----------- | ------------------ | ------------ |
| 新授课      | BOPPPS             | 备课材料框架 |
| 复习课      | BOPPPS（压缩新授） | 布鲁姆层级   |
| 实验/探究课 | 5E                 | BOPPPS       |
| 习题课      | 布鲁姆层级         | 分层差异化   |
| 单元起始课  | 大单元             | UbD          |
| 微课/赛课   | BOPPPS             | 5E           |
| 备课资料堆  | 备课材料框架       | 资源类型兜底 |

课型只是线索：名称看不出课型时，按课题与用途归类，不凭学科推断。复习课若材料以知识梳理、错题、复习卷为主，按用途分区（知识梳理｜练习与检测｜总结提升）即可，不必硬套 BOPPPS 六环节；只有名称明确出现课堂环节时才用环节框架。

**常见误区**

- 把“按文件类型分组”当教学整理——类型只能兜底，且要说明这是降级方案。
- 分区过多（超过六个）——布局拥挤甚至超出视口，画布更难读，宁合并不拆碎。
- 凭学科推课型、凭课题推难度——名称不提供这些信息。
- 把完整课件塞进某一环节——它通常覆盖多个环节，应进“整课材料”。
- 把“练习”猜成前测或后测——时点不明就放“练习与检测”。
- 因没看到某类材料就断言环节缺失——完整课件内部可能已有。
- 为凑齐框架硬造空分区——空组不提交，缺什么就说什么。
- 超时后补一次整理——上次布局可能已经应用。报告结果待核对，下一次明确整理时读取最新画布。
- 给分区叠加课题前缀（`观沧海 · 情境导入`）——标题只写分类；多课题各自成套时直接按课题命名分区。
- 为用途不明的材料生造分类——保留已有分类，散落材料可列为待确认或未分类。

**解释话术的三种长度**

1. 默认交付（整理后）：一张表（分区 / 材料数 / 归类依据）+ 一句框架价值，如“按 BOPPPS 的课堂组织顺序整理，便于按课堂节奏取用”，再加一行未分组说明；总长不超过 10 行。
2. 追问框架（5 行内）：框架是什么 → 为何匹配这份画布（引 1–2 个名称）→ 它解释不了什么。
3. 追问细节：按本文件对应小节展开环节定义、归类判据、学科适配与局限，仍以实际读取的范围为界，不能把抽样或标题判断冒充全文理解。
