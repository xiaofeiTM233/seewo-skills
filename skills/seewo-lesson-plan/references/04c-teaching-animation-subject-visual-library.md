# 各学科可视化语言库与课标依据（初步线索）

> **重要提示**：本文件收录的课标条目号与原文片段来自历史资料整理，**仅作为设计初步线索使用**。任何面向用户的正式课标依据引用，都必须先用关键词"义务教育{学科}课程标准日常修订版2022年版2025年修订"通过网络搜索工具核实原文，以搜索结果为准，不能直接照抄本文件内容作为最终依据。

> **学科适用性说明**：本专家的方法论对**理科/科学类学科（物理、化学、生物学、科学、数学、地理、信息科技）**的适配度最高，因为这些学科天然存在大量"抽象规则/微观尺度/动态过程"型难点；对**人文类学科（语文、历史、道德与法治、英语）**，本专家的能力边界收窄为"动态过程类"难点的可视化（如历史事件的时间演进、地理运动过程），情感类、价值类、语言表达类内容不属于本专家核心能力，应优先转介"课件呈现设计师"处理图文排版与情感渲染。

## 1. 物理

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 物理观念、科学思维（模型建构）、科学探究 |
| 典型"抽象/微观/动态"难点清单 | 电流的形成（微观电荷定向移动）、电路中电流电压的分配规律、原子的核式结构模型、凸透镜/平面镜成像规律（几何光路动态关系）、电磁感应中导体运动产生感应电流的条件、串并联电路电流电压特点 |
| 课标原文线索（待网络搜索核实） | "有条件的学校可配备数字化实验仪器，增强实验现象的可视化和实验数据采集的实时化"；"科学思维……是建构物理模型的抽象概括过程" |
| 可视化设计要点 | 光学类难点（平面镜/凸透镜成像）最适合"几何光路动态生成"手法——让光线随物距的拖动实时重新绘制；电磁类难点（电流形成、电磁感应）最适合"微观视窗"手法——在宏观电路图旁开一个放大窗展示微观粒子行为；力学类难点适合"矢量箭头动态叠加"手法 |

## 2. 化学

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 化学观念、科学思维（"从宏观、微观、符号相结合的视角探究物质及其变化规律"） |
| 典型"抽象/微观/动态"难点清单 | 分子、原子的构成与运动、原子结构（原子核+核外电子）、化学反应的微观本质（原子的重新组合）、质量守恒定律的微观解释、燃烧与灭火的条件（多变量交互验证） |
| 课标原文线索（待网络搜索核实） | "结合学生熟悉的现象和已有的经验，通过实验探究、模型拼插等活动或动画模拟等可视化手段……引导学生从分子、原子等微观视角认识物质及其变化，帮助学生建立宏观与微观间的联系"；"基于'宏观—微观—符号'多重表征设计学习活动" |
| 可视化设计要点 | 化学是义务教育课标中较为明确点名"动画模拟"作为教学手段的学科，是"多重表征映射法"的直接课标来源；设计时务必让"宏观现象画面"与"微观粒子重组动画"在同一交互界面中可切换对照，并配合化学方程式的符号呈现，构成完整的三重表征闭环 |

## 3. 生物学

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 生命观念（结构与功能观）、科学思维、探究实践 |
| 典型"抽象/微观/动态"难点清单 | 血液循环（体循环+肺循环的路径与气体交换机制）、尿液的形成过程（肾单位滤过/重吸收机制）、细胞的结构与分裂过程、眼球成像原理、光合作用/呼吸作用的物质能量转化 |
| 课标原文线索（待网络搜索核实） | "运用示意图或模型等方式，展示和说明细胞各结构的功能及其相互关系"；"可以运用文字、图片、动画、视频、模拟实验等数字化资源，改进教学内容的呈现方式……增强教学的直观性、生动性和丰富性" |
| 可视化设计要点 | 课标中"尿液的形成过程"教学案例展示了"教师画出示意图→学生猜想画模式图→逐步修正→教师总结完整模式图"的渐进构建式教学法，可迁移为动画的"分步揭示"交互设计 |

## 4. 科学（小学/初中一体化）

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 科学观念、科学思维、探究实践 |
| 典型"抽象/微观/动态"难点清单 | 地球的自转与公转（昼夜交替、四季变化成因）、日食月食节气月相的成因（多天体相对运动）、水循环过程、天体系统的层次与相对位置 |
| 课标原文线索（待网络搜索核实） | "借助信息技术手段，让学生通过观看动画演示或纪录片，加深对天体系统的大小、相对位置、层次等概念的认识"；"利用三球仪模拟地球、月球和太阳的相对运动，解释日食、月食、节气、月相的成因" |
| 可视化设计要点 | 天文类难点是"动态"特征最典型的一类，课标明确建议用实物模拟（三球仪、地球仪+手电筒），是 HTML 动画替代实物教具的最佳场景：可以自由调节转速、视角（俯视/侧视切换） |

## 5. 数学

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 几何直观、模型观念、抽象能力 |
| 典型"抽象/微观/动态"难点清单 | 函数图像随参数变化的规律（如二次函数开口/顶点随系数变化）、几何图形的动态变换（旋转、平移、对称）、数形结合类问题、统计概念的动态生成过程 |
| 课标原文线索（待网络搜索核实） | "重视数学内容的直观表述，处理好直观与抽象的关系"；"利用数学专用软件等教学工具开展数学实验，将抽象的数学知识直观化" |
| 可视化设计要点 | 数学是"图示即目标"的学科，动画中的交互控制点应直接对应函数/几何对象的参数，让学生通过连续拖动参数直接看到图像的连续变化 |

## 6. 地理

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 区域认知、综合思维、地理实践力 |
| 典型"抽象/微观/动态"难点清单 | 地球的自转和公转运动、太阳高度角与季节变化、水循环、板块运动、气压带风带的形成与移动 |
| 课标原文线索（待网络搜索核实） | "本主题内容在教学情境创设上要突出直观性……重视使用与主题相关的图像、视频等"；"提供室内地理模拟实验的基本实验材料，配备相关的数字资源" |
| 可视化设计要点 | 地理难点大多涉及空间尺度的三维关系，可采用"多视角切换"手法弥补平面呈现的局限 |

## 7. 信息科技

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 计算思维、信息意识 |
| 典型"抽象/微观/动态"难点清单 | 算法执行流程（如排序、查找算法的逐步执行）、网络数据的发送接收原理（TCP/IP分层）、物联网系统的工作流程 |
| 课标原文线索（待网络搜索核实） | "通过图解、动画等，将传统邮件与电子邮件的收发环节进行类比……认识'协议'对于互通互联的重要价值"；"能利用自然语言、流程图等方式，描述求解简单问题的算法" |
| 可视化设计要点 | 最适合"逐步执行动画"手法——把算法/协议流程拆解为可以单步点击前进的关键帧序列，每一步高亮当前正在执行的操作 |

## 8. 历史

| 项目 | 内容 |
|---|---|
| 核心素养关联 | 时空观念 |
| 典型"抽象/微观/动态"难点清单 | 历史事件的发展演变过程、疆域/势力范围的历史变迁 |
| 课标原文线索（待网络搜索核实） | "教师要努力将现代信息技术与历史教学内容的展现相结合，通过多媒体手段呈现具体的、形象的、动态的、多维度的历史情境" |
| 能力边界提示 | 多数历史难点属于"史实理解、史料辨析、价值判断"类，不属于本专家核心能力范围；仅当难点确实具备"动态演进过程"特征时可介入设计可拖动时间轴的可视化工具，其余内容建议转介"课件呈现设计师" |

## 9. 语文 / 10. 英语 / 11. 道德与法治

| 学科 | 能力边界说明 |
|---|---|
| 语文 | 核心素养以语言运用、审美创造、文化自信为主，难点大多是"理解与表达"而非"机制"，不属于本专家核心能力；若涉及"情节发展的时间线"等动态过程类内容，可提供极简辅助工具，主体设计工作建议转介"课件呈现设计师" |
| 英语 | 语法结构类难点（如时态变化）理论上可做"时间线动画"辅助理解，但整体属于边缘能力，非核心场景 |
| 道德与法治 | 核心诉求是情感共鸣与价值引领，本质上不是"机制类"难点，不适合本专家的方法论体系，应转介情境案例设计或"课件呈现设计师" |

> **给使用者的建议**：拿到任何一个需求，先用"设计哲学"里的三个特征（看不见/想不出/说不清先后）快速判断——理科/科学类学科的多数教学难点天然适配本专家；人文类学科只有少数"动态演进过程"类内容适配，多数内容应转介课件/教学设计类专家。
