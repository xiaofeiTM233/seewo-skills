# 典型问题应对示例

> 以下 3 个示例对照三种任务模式（原理讲解/难点可视化/仿真资源），展示"通用方法论 + 学科课标插槽"的完整组合产出方式。示例中的课标条目号为历史资料整理结果，实际使用时仍需按 Agent 主文件工作流程第二步的要求，通过网络搜索核实课标原文，不能直接照抄示例中的条目号。

## 示例1【原理讲解】初中物理"电流的形成"

```
【学科/学段/内容】初中物理 · 第四学段（7~9年级）· 电流的形成
【课标依据】需网络搜索核实"义务教育物理课程标准日常修订版2022年版2025年修订"中"电和磁"
           一级主题下关于电流、电压、电源与用电器相关的具体条目——"电流的形成"是建立
           "电流"概念前必须讲清的微观机制前提
【难点诊断】同时具备"看不见"（电子尺度不可观察）、"微观"（金属导体内部的电荷载体）、
           "动态"（漂移过程随时间演化）三个特征，是最典型的目标场景
【机制主张】电流的形成，本质是导体中原本做无规则热运动的自由电子，
           在电源建立的电场作用下，叠加了一个整体的定向漂移
【现象层情境】"同样的电池，为什么不同灯泡亮度不一样？"——制造"我看到结果，但不知道电路内部
             发生了什么"的认知缺口
【多重表征映射】
  宏观现象层：开关闭合前后灯泡是否发光、电流表是否有读数
  微观机制层：导线内部"微观视窗"中，自由电子从无序热运动过渡到定向漂移的动画
  符号/数据层：习惯电流方向箭头标注（与电子移动方向相反），配合电源正负极标识
【交互控制点】
  ①"开关断开/闭合"切换 → 探究问题："开关断开时电子在做什么运动？闭合后有什么变化？"
  ②"电源正负极反接"切换 → 探究问题："电场方向变了，电子漂移方向会怎样变化？电流方向呢？"
【叙事结构】起（情境冲突）→承（开关断开时的纯热运动状态）→转（闭合后定向漂移+反接对比）
           →合（"电流方向由电源决定，本质是电荷定向移动的外部表现"结论静止帧）
【交付形态】自建单文件 HTML
【设计说明】用"金属晶格+自由电子小球"的微观视窗手法，配合开关状态与正负极反接两个交互点，
           让学生通过操作直接观察"无序热运动"与"定向漂移叠加热运动"两种状态的区别，
           这正是传统讲授最难讲清楚、而动画最适合展现的一层
```

**实现要点参考**：用内联 SVG 绘制简化电路图（电源+开关+灯泡+导线），在导线下方开一个"微观视窗"用动态小球模拟自由电子的热运动与定向漂移叠加效果，配色遵循色彩语义系统（青色=自由电子/负电荷，红色=金属正离子），提供"开关断开/闭合/电源反接"三个交互按钮，每次切换都同步更新画面与文字说明。

## 示例2【难点可视化】初中生物"血液循环"

```
【学科/学段/内容】初中生物学 · 第四学段（7~9年级）· 血液循环（体循环与肺循环）
【课标依据】需网络搜索核实"义务教育生物学课程标准日常修订版2022年版2025年修订"中
           关于血液循环系统组成、体循环肺循环功能、气体交换部位的具体条目与学业要求
【难点诊断】"看不见"（体内管道系统无法直接观察）+"动态"（血液沿闭合回路持续流动）+
           一定程度的"抽象"（体循环肺循环两条路径如何在心脏交汇，学生常混淆方向）
【机制主张】血液循环是心脏驱动血液沿两条闭合路径流动的过程：体循环负责给全身"送货收垃圾"，
           肺循环负责给血液"换气"，两条路径在心脏首尾相连构成完整回路
【可视化方案设计】（对应模式B诉求，方案要点如下）
  方案手法：路径动画 + 颜色渐变换色 + 视角切换（全景/仅肺循环/仅体循环）
  关键帧规划：
    帧1 全景展示两条路径的闭合回路结构（心脏四腔+主要血管+肺+全身组织四个节点）
    帧2 血细胞沿路径移动的小球动画，在"肺部毛细血管"和"全身毛细血管"两个节点
        触发颜色渐变（蓝→红 或 红→蓝），用颜色变化直接呈现"气体交换/物质交换正在发生"
    帧3 允许学生单独隔离查看"只看肺循环"或"只看体循环"，降低同时观察两条路径的认知负荷
  交互控制点：
    ①"全景/仅肺循环/仅体循环"三态切换 → 探究问题："肺循环和体循环分别负责什么任务？"
    （如学生需要更精细控制，可进一步增加"播放速度"滑块，观察血液流动的连续性）
【交付形态】自建单文件 HTML，按方案落地实现
【设计说明】把"血液循环"这个经典难点的核心突破点放在"颜色变化"上——学生只要记住
           "红色=富氧血，蓝色=缺氧血"这一套语义，就能通过观察小球在毛细血管节点的
           变色时刻，直接理解"气体交换发生在哪里、发生了什么"，不需要死记路径顺序
```

**实现要点参考**：用简化拓扑图表示心脏四腔、肺、全身组织三大节点及其连接血管，血细胞用沿路径运动的小球表示，并在关键节点（肺部/全身毛细血管）触发颜色渐变，提供"全景/仅肺循环/仅体循环"三个视角切换按钮，帮助学生先建立整体路径感，再分别理解两条循环各自的功能意义。

## 示例3【仿真资源】初中物理"凸透镜成像"

```
【学科/学段/内容】初中物理 · 第四学段（7~9年级）· 凸透镜成像规律
【课标依据】需网络搜索核实"义务教育物理课程标准日常修订版2022年版2025年修订"中
           关于凸透镜/凹透镜对光的作用、探究凸透镜成像规律的具体条目
【难点诊断】"抽象"（成像规律涉及物距/像距/焦距三者的几何关系，公式化理解门槛高）+
           "动态"（物距连续变化时，像的性质发生五种质变，静态图只能定格其中一种情况）
【仿真资源双轨策略执行】

  轨道1·现成资源检索结果：
  - PhET"Geometric Optics"几何光学仿真（美国科罗拉多大学博尔德分校出品，全球公认权威、
    对教学场景免费开放）：功能完整，可自由调节透镜曲率半径、折射率、物距，实时显示光线
    追迹和像的位置，是国际上最常用的光学教学仿真之一。
    注意事项：①默认界面为英文（有多语言包，但中文包在部分版本可能不全，需要教师提前
    切换测试）；②依赖网络访问 phet.colorado.edu 域名，部分校园网环境访问可能不稳定；
    ③功能强大但对初中生而言操作面板略复杂（曲率半径/折射率等参数超出义务教育课标要求
    的探究变量范围，实际教学建议只用"移动物体"这一个核心交互，其余参数保持默认，避免
    分散学生注意力到课标未要求的变量上）。
  - 国内也有若干中文初中物理仿真实验站点提供"凸透镜成像"专项仿真，优点是中文界面、
    变量范围贴合初中课标，缺点是稳定性、长期可访问性因具体运营方而异，建议教师使用前
    先自行验证访问稳定性，若计划长期使用或离线使用，建议采用轨道2的自建方案作为备份。

  轨道2·自建保底方案（推荐作为首选交付物）：
  - 单文件 HTML，不依赖任何网络连接，可直接投屏或拷贝给学生在自己电脑上打开；
  - 核心交互只保留"物距 u""焦距 f"两个滑块（贴合课标探究范围），并提供
    "u>2f / u=2f / f<u<2f / u=f / u<f" 五个快捷按钮，一键跳转到五种经典成像情况，
    降低学生自行摸索的时间成本；
  - 实时计算并展示像距、虚实、正倒、放大缩小四项结果，并用文字总结每种情况对应的
    生活应用（照相机/投影仪/放大镜），直接对应课标"了解凸透镜成像规律的应用"要求。
【交付形态】自建单文件 HTML + 现成资源使用建议说明
【设计说明】本例是"仿真资源"模式的典型处理方式——不是简单丢一个链接了事，而是先诚实
           评估现成资源的优势和风险，再用自建方案兜底，确保用户"要能直接拿去用"的
           诉求无论网络环境如何都能被满足
```

**实现要点参考**：基于薄透镜成像公式 `1/f = 1/u + 1/v` 实时计算像的位置与性质，用 SVG 动态绘制物体、透镜、光路（平行光线+过光心光线）与像的位置，滑块可连续调节物距与焦距，并提供五种经典情况的一键跳转按钮，结果面板实时显示像距、虚实、正倒、大小四项判断结果。
