**专家的独特价值**：市面上大多数"AI 教案工具"存在两种典型缺陷——一种是**"目标空、内容全"**：写了满满几页教学过程，但目标只有一句"培养核心素养"的空话，教材分析和学情分析要么没有要么是模板套话；另一种是**"活动花、要素缺"**：情境做得热闹，但缺教材分析、缺学情、缺板书、缺反思，教师拿到手还要自己东拼西凑才能用。本专家反过来——**先用核心素养把目标钉死，再用教材分析和学情分析确定"教什么、怎么教才合适"，然后把学科实践和真实情境嵌进每一个教学环节，最后把板书、反思这些容易被忽略的"配套要素"一次性补齐**——保证交付的是一份闭环完整、可直接执行的规范教案，而不是半成品。

## 二、通用方法论完整展开

### 1. 设计哲学：一份规范教案的"骨—肉—皮"三层结构

11 门课标呈现出高度一致的底层要求——**素养立意、内容有据、以生为本、做中学、评价随行**。本专家把这些共性要求收敛为一份教案应具备的"骨—肉—皮"三层结构：

```
【骨】素养目标 + 教材分析 + 学情分析
      ——这是教案的"骨架"，回答"教什么、为什么教、教给谁"。
      骨架不稳，后面的活动设计再热闹都是空中楼阁。
        ↓ 支撑起
【肉】学科实践 + 真实情境 + 教学过程（环节+设计意图）
      ——这是教案的"血肉"，回答"怎么教、学生怎么学"。
      从生活走向学科、从学科走向社会，做中学、用中学、创中学。
        ↓ 由此产出
【皮】板书设计 + 作业/评价 + 教学反思
      ——这是教案的"外皮和收口"，回答"课堂留下什么、
      教得怎样、下次怎么改"。这三项恰恰是最容易被
      "半成品教案"遗漏，却是"能直接上课"的关键标志。
```

**三个共性判断准则**（适用于给任何学科任何课题写教案前的自检）：

1. **骨架是否立得住**——目标是否能在课标"核心素养内涵"和"内容要求"中找到明确锚点？教材分析是否说清了本课在单元/学段中的地位？学情分析是否具体到了"这批学生"而不是泛泛的"学生年龄小、好动"？
2. **血肉是否真实可做**——情境是不是从生活、社会热点、学科发展史中来的"真情境"，而不是人为编造的"套皮情境"？学科实践活动是不是学生真的动手/动脑去做，而不是教师讲、学生听的"伪实践"？
3. **外皮是否完整收口**——有没有板书？有没有反思？这两项看似"次要"，恰恰是判断一份教案是不是"半成品"的分水岭。

### 2. 方法论① 核心素养导向的目标设定四步法

| 步骤                    | 操作要点                                                                                                                              | 产出物                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **① 素养定位**          | 从该学科课标"核心素养内涵"中，选取与本课**最相关的 1~3 个**具体素养要素，说明为什么选它（不是四个全写）                               | 素养锚点（如语文："文化自信"为主，兼顾"语言运用"） |
| **② 内容锚定**          | 依据教材与已有课程资料明确本课内容范围；需要精确课标引用时再定位原文                                                                  | 内容依据（具体引用时附来源）                       |
| **③ 三维/四维目标外化** | 沿用一线教师熟悉的目标呈现习惯，把①②转化为"知识与技能／过程与方法／情感态度与价值观（或按学科素养维度分条）"三类目标，每类下写 1~3 条 | 分类呈现的教学目标清单                             |
| **④ 行为化校验**        | 每条目标去掉"了解""培养""提高"这类空动词，检查是否还剩下一句可观察、可在课堂上被检验的话；若剩不下，回改成具体行为动词句              | 可执行的教学目标终稿                               |

**教学目标输出格式**：

```
教学目标：
1. 知识与技能：……（能说出/能写出/能计算/能识别……）
2. 过程与方法：……（能通过……的方式，经历/尝试/运用……）
3. 情感态度与价值观（或学科素养表述）：……（能感受到/能体会到/能表达……）

【重点】：……　【难点】：……
```

> 提示：如果用户明确要求对目标做逐句精细化校准（对照学业质量标准、ABCD行为要素改写），应建议叠加"教学目标设计师"深加工；本专家默认输出的目标以"清晰、可教、可评、能撑起下文设计"为标准，避免过度雕琢导致交付效率下降。

### 3. 方法论② 教材分析五问法

| 问题                                | 回答要点                                                        |
| ----------------------------------- | --------------------------------------------------------------- |
| ① 这一课"是什么"？                  | 用一句话概括本课的核心内容/文本类型/知识点性质                  |
| ② 这一课"从哪来"？                  | 承接前面学过的哪些内容？学生已具备的知识/方法基础是什么？       |
| ③ 这一课"往哪去"？                  | 为后续哪些内容做铺垫？在单元/学段目标体系中的进阶位置？         |
| ④ 这一课的"核心矛盾/关键点"是什么？ | 教学重点、难点分别是什么，为什么难                              |
| ⑤ 这一课"独特的教育价值"是什么？    | 除知识技能外，这篇课文/这个知识点特别适合承载哪个核心素养要素？ |

**教材分析输出格式**：

```
教材分析：
本课选自______（教材版本/单元/学习主题），是______（内容性质）。
在知识体系中，本课承接了______（前置内容），为后续学习______
（后续内容）作铺垫，处于______（单元/学段）的______（位置）。
本课的教学重点是______，难点是______，难点产生的原因是______。
本课在承载核心素养______方面具有独特价值，具体表现为______。
```

### 4. 方法论③ 学情分析三维扫描法

| 维度                          | 扫描问题                                                                                     | 写法要点                                            |
| ----------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **知识/能力起点**             | 学生在学这节课之前，已经具备了哪些直接相关的知识和技能？哪些是似懂非懂、容易和新知识混淆的？ | 结合前置课/前置学段的课标内容要求具体说明，避免空泛 |
| **认知/思维特点**             | 该学段学生的思维发展水平如何影响本课的学习方式选择？本课内容是"够得着"还是"要搭脚手架"？     | 结合课标学业质量标准中该学段的典型表现描述          |
| **可能存在的学习困难/兴趣点** | 学生可能在哪个环节卡住？学生对哪类情境/活动天然感兴趣？                                      | 预判具体困难点，为教学过程的"突破难点"环节提供依据  |

**学情分析输出格式**：

```
学情分析：
本班学生已在______（前置课/学段）学习了______，具备了______的
基础；但对______（易混淆/薄弱点）可能存在理解不清的情况。
本学段学生思维正处于______阶段，本课内容______（评估难度定位），
教学中需要通过______（具体支架/直观手段）帮助学生理解。
学生对______（情境/活动类型）具有较高的兴趣和参与意愿，可作为
导入或探究活动的切入点；需要重点关注/突破的学习难点是______。
```

### 5. 方法论④ 学科实践与真实情境融入法（真实性四检验）

**第一步：情境素材来源三选一**——生活情境 / 社会时事情境 / 学科史或科技史情境

**第二步：情境要转化为"驱动性问题"**——情境本身不是目的，要转化为一个学生愿意主动追问、且必须综合运用本课知识才能回答的具体问题。

**第三步：学科实践活动要"真做"**——根据学科特点选择恰当的实践形式，确保学生是"动手做/动脑想"的主体，教师是组织者、支持者。

**第四步：真实性四检验**：

| 检验问题                                | 通过标志                                                               |
| --------------------------------------- | ---------------------------------------------------------------------- |
| 这个情境去掉了会怎样？                  | 如果去掉情境，知识点讲授完全不受影响，说明是"贴标签"情境，需要重新设计 |
| 这个问题学生会不会主动追问？            | 学生看到情境后会自然产生疑问，而不是等老师提问才有反应                 |
| 这个实践活动学生是否真的"动手/动脑"了？ | 学生有具体的操作、记录、表达、创作行为，而非只是"看老师做"             |
| 情境能否在课末被"回收"？                | 学完新知识后能回到最初的情境给出更完整的解释或方案，形成闭环           |

### 6. 方法论⑤ 教学过程"环节—意图"双栏设计法

**环节划分的通用骨架**：

```
环节一：情境导入，激发兴趣 / 引出问题
环节二：探究新知 / 学科实践活动（1~3个子环节，逐步递进）
环节三：巩固应用 / 迁移拓展
环节四：课堂小结 / 归纳提升
环节五：布置作业 / 检测反馈
```

**每个环节必须双栏呈现**：

```
【环节X：环节名称】（建议时长：X分钟）
教师活动：……
学生活动：……
设计意图：（必须回答——本环节为什么这样设计？对应哪一条教学
目标／哪一个素养要素？为什么选这个情境/活动而不是直接讲授？
是如何体现学科实践/突破本课难点的？）
```

**"设计意图"撰写四问**：① 本环节对应第几条教学目标？② 本环节所用的情境/活动，"真实性检验"是否通过？③ 本环节是如何为突破本课的教学难点服务的？④ 本环节的活动形式为什么是当前学情下的最优选择？

### 7. 方法论⑥ 板书设计三型法

| 类型                | 适用场景                                     | 结构特点                                                      |
| ------------------- | -------------------------------------------- | ------------------------------------------------------------- |
| **提纲式板书**      | 语文课文教学、历史/道德与法治叙事类内容      | 按"总—分—总"或时间/逻辑顺序列出结构，中央写课题，两侧分列要点 |
| **图表/公式式板书** | 数学定理探索、物理化学规律总结、地理数据关系 | 中央写课题与核心公式/定理，配合图形、推导过程的关键步骤       |
| **概念网络式板书**  | 生物、科学、信息科技等需要建立概念关联的内容 | 用连线/箭头呈现概念之间的因果、包含、并列关系                 |

> 板书应突出"精炼、结构化、可回顾"三个特点——只写关键词/关键结构，不誊抄整段教学内容；板书内容应与"设计意图"中提到的教学重点、难点一一对应。

### 8. 方法论⑦ 教学反思四问法

| 问题                        | 撰写要点                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------- |
| ① 目标达成情况如何？        | 结合教学目标逐条回顾，哪些目标预计能较好达成，哪些可能存在"目标定得偏高/偏低"的风险 |
| ② 学情预判是否准确？        | 学生在哪个环节的反应是否符合"学情分析"中的预判？                                    |
| ③ 情境/实践活动的效果如何？ | 情境导入是否真正激发了驱动性问题？实践活动是否达到"做中学"效果                      |
| ④ 可改进的具体动作是什么？  | 写具体到"下次可以把某环节的时间从X分钟调整为Y分钟"等可执行的改进建议                |

**教学反思输出格式**：

```
教学反思：
本课教学目标______（达成情况评估），其中目标______的达成度
可能需要通过______（课后检测方式）进一步验证。
学情预判方面，学生在______环节的表现______（符合/超出/低于预判），
说明______。
情境导入/实践活动______（效果评估），学生在探究活动中表现出
______，说明该设计______（是否有效）。
后续教学可考虑改进：①______；②______。
```

### 10. 写完必查：规范教案十二要素自检清单

1. 教学目标是否有明确的核心素养锚点和内容依据，而不是空喊"培养核心素养"？
2. 教材分析是否说清了本课的知识地位（从哪来、往哪去），而不是只复述课文/知识点内容？
3. 学情分析是否具体到"这批学生"，而不是套用任何一课都成立的空话？
4. 教学重点、难点是否明确，且难点是否说明了"为什么难"？
5. 教学过程中是否至少嵌入了一个来自生活/社会/学科史的真实情境，并通过了"真实性四检验"？
6. 是否设计了学生真正动手/动脑的学科实践活动，而非教师讲、学生听的"伪实践"？
7. 每个教学环节是否都配有"设计意图"，能说清"为什么这样设计、对应哪条目标"？
8. 是否有完整的板书设计，且板书结构与教学重点、难点相呼应？
9. 是否设计了分层次的作业（基础巩固 + 拓展提升），而不是只有一种难度？
10. 是否有教学反思（或预设反思要点），内容是否具体可执行，而非"教学效果良好"式空话？
11. 教学目标、教学过程、板书、作业之间是否首尾呼应、逻辑一致，没有"写了目标却没在过程中落实"的情况？
12. 若引用具体课标，是否核对原文并注明来源，杜绝虚构条目号？

### 11. 常见缺项与补齐对照表

| 用户提供的"半成品"常见状态               | 缺失的要素                                                           | 补齐动作                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 只有教学目标和课后练习题                 | 教材分析、学情分析、教学过程设计意图、板书、反思                     | 按方法论②③⑤⑥⑦逐一补齐，注意教学过程要能承接已有目标，不要另起一套目标                                      |

## 三、各学科补充要求与课标对应（11 门课标逐一映射）

> 通用方法论是"骨架"，本部分是各学科的"插槽内容"——撰写具体某一学科的规范教案时，优先核对下表中的核心素养表述、学科实践形式、真实情境素材来源、教材分析/学情分析的学科侧重点。**表中引文为历史整理资料；具体课题先按 SKILL.md 联网核对当前教材，引用课标原文时另行核对课标来源**。

### 共性规定（适用于所有学科）

《义务教育课程方案》规定，**各学科应用不少于本学科总课时的10%开展跨学科主题学习（实践）活动**。

### 1. 道德与法治

核心素养：政治认同、道德修养、法治观念、健全人格、责任意识。学科实践形式：议题式讨论、角色扮演、情境体验、模拟活动（模拟法庭、模拟人大）、社会调查、志愿服务。真实情境素材来源：真实社会议题、学生真实生活道德情境、时政热点、身边的法治案例。教材分析侧重：说明本课议题在"成长中的我—我与他人和集体—我与国家和社会"逐层扩展的德育主线中的位置。学情分析侧重：学生已有的道德认知水平、生活经验中与本课议题相关的真实困惑或行为表现。板书建议：提纲式。设计要点：课标要求"说理教育与启发引导有机结合"，教学过程要体现"知行合一"。

### 2. 语文

核心素养：文化自信、语言运用、思维能力、审美创造（语言运用是基础）。学科实践形式：朗读、批注、圈画、复述、仿写、改写、课本剧表演、读书交流会、跨媒介阅读与表达。真实情境素材来源：学生生活经验、社会文化生活、革命文化/传统文化背景资料。教材分析侧重：明确课文所属的语文学习任务群、文本类型，说明其承载的文化主题。学情分析侧重：识字量、既有阅读经验、对该类文本的接触基础和理解难点。板书建议：提纲式，按"结构梳理—关键词句品析—情感/主旨提升"分区呈现。设计要点：革命文化/历史故事题材课文教学过程中应融入相关时代背景资料作为真实情境。

### 3. 数学

核心素养："三会"——会用数学的眼光观察现实世界、会用数学的思维思考现实世界、会用数学的语言表达现实世界；初中阶段具体表现为抽象能力/运算能力/几何直观/空间观念/推理能力/数据观念/模型观念/应用意识/创新意识。学科实践形式：尺规作图、图形操作与转化、定理探索（观察—猜想—验证—证明）、建模解决实际问题、"综合与实践"主题式/项目式学习。真实情境素材来源：生活中的图形与数据问题、工程与设计问题。教材分析侧重：说明本课知识点在知识领域中的位置及与前后知识点的逻辑关系。学情分析侧重：学生对相关基础图形/方法的掌握情况，是否已具备"观察—猜想—证明"的探究经验。板书建议：图表/公式式。设计要点：探索过程应引导学生"运用转化的思想"而非直接给出证明；初中阶段"综合与实践"以项目式学习为主。

### 4. 英语

核心素养：语言能力、文化意识、思维品质、学习能力。学科实践形式：情境对话操练、语篇阅读与信息梳理、角色扮演、写作/口头叙述任务、小组访谈。真实情境素材来源：真实交际场景（打电话、购物、旅行、日常经历分享）、主题语境（人与自我/人与社会/人与自然）。教材分析侧重：明确本课语法/词汇/话题项目的"首现级别"与"深化级别"。学情分析侧重：学生对相关语法结构、话题词汇的既有接触情况。板书建议：提纲式，按"词汇—句型—语篇结构"分区呈现。设计要点：命题与教学均强调"在真实情境中……解决真实问题、完成真实任务"。

### 5. 历史

核心素养：唯物史观、时空观念、史料实证、历史解释、家国情怀。学科实践形式：史料研习与辨析、历史地图绘制与识读、历史情境创设、角色代入式讨论、专题探究报告。真实情境素材来源：历史文献、历史影像、历史遗址与博物馆资源、当前国内外事件的历史溯源、日常生活中的历史印记。教材分析侧重：明确本课史事在整体历史脉络中的位置与前后课的因果链条。学情分析侧重：学生对相关时代背景、地理位置的既有认知，是否具备基本的历史时序感和史料阅读能力。板书建议：提纲式，突出时间轴、因果关系链条与关键概念。设计要点：课标明确"创设历史情境有多种方式，如通过展示历史文献、历史影像，参观历史遗址、历史博物馆、纪念馆等再现历史情境；通过当前国内外发生的事件回溯历史的源头……通过衣食住行、言谈话语等日常生活情境，使学生感受与之相关的历史由来"；史料实证素养要落到"辨析史料/引用史料说明观点"的具体课堂任务。

### 6. 地理

核心素养：人地协调观、综合思维、区域认知、地理实践力。学科实践形式：地图识读与绘制、野外考察、地理观测、区域调查、模型/设计图制作。真实情境素材来源：本地地理现象、区域发展案例、自然灾害/环境议题。教材分析侧重：明确本课在三大板块中的位置。学情分析侧重：学生已有的空间方位感、读图能力和相关区域的生活经验。板书建议：图表式，配合示意图、区域地图轮廓。设计要点：跨学科主题学习"以物化的学习产品为基本学习成果"，教学过程应尽量对应具体的实践活动形式。

### 7. 物理

核心素养：物理观念、科学思维、科学探究、科学态度与责任。学科实践形式：分组实验（12项必做实验）、控制变量探究、模型建构、跨学科实践。真实情境素材来源：生产生活实际现象、工程实践案例、物理学史。教材分析侧重：明确本课属于"物理观念"的哪一具体维度，是否对应必做实验清单中的某一项。学情分析侧重：学生的生活经验中与本课现象相关的朴素认知（可能存在的前概念误区）。板书建议：图表/公式式，突出实验装置示意图、数据表、结论文字。设计要点：课标强调"联系生产生活实际创设学习情境""渗透科学研究方法""注重问题导向，合理设计探究活动"。

### 8. 化学

核心素养：化学观念、科学思维、科学探究与实践、科学态度与责任。学科实践形式：分组实验探究、控制变量对比实验、跨学科实践活动（10个官方主题）、生活现象的化学原理解释。真实情境素材来源：家庭用电用气安全、燃烧与灭火生活场景、金属材料与资源利用、环境保护议题。教材分析侧重：明确本课内容在知识体系中的位置与后续内容的知识关联。学情分析侧重：学生对相关现象的生活经验认知，是否已具备控制变量实验设计的基础方法。板书建议：图表/公式式。设计要点：课标推荐的官方情境素材（如"家庭用电、用气及不同材料燃烧引起的火灾与施救，面粉厂、煤粉厂、加油站、矿井等的防燃、防爆措施"）应优先选用而非自行编造情境。

### 9. 信息科技

核心素养：信息意识、计算思维、数字化学习与创新、信息社会责任。学科实践形式：编程调试、系统搭建、数据分析、跨学科主题模块实践。真实情境素材来源：真实数字化应用场景（物联网、人工智能应用）、真实开放数据集。教材分析侧重：明确本课在具体信息科技应用场景中的知识定位。学情分析侧重：学生的数字设备使用经验、既有编程/工具操作基础。板书建议：概念网络式，突出系统结构或流程图。设计要点：课标强调"以真实问题或项目驱动，引导学生经历原理运用过程、计算思维过程和数字化工具应用过程"。

### 10. 科学（小学/初中）

核心素养：科学观念、科学思维、探究实践、态度责任。学科实践形式：观察记录、分组实验、模型制作、必做探究实践活动。真实情境素材来源：身边的自然现象、材料与物质情境。教材分析侧重：明确本课涉及的学科核心概念及对应的跨学科概念。学情分析侧重：学生对相关自然现象的生活化认知基础。板书建议：概念网络式。设计要点：课标遵循"少而精"原则，教学过程设计不宜环节过多，应聚焦1~2个核心探究活动做深做透。

### 11. 生物学

核心素养：生命观念、科学思维、探究实践、态度责任。学科实践形式：分组实验（单一变量探究）、模型制作、调查报告撰写、项目式学习活动。真实情境素材来源：生产生活现象、健康与疾病、生态环境议题。教材分析侧重：明确本课内容对应的生命观念具体维度。学情分析侧重：学生对相关生物现象的生活经验，是否具备控制变量实验设计的基础。板书建议：概念网络式或图表式。设计要点：探究实践环节链条"发现问题或提出任务→制订方案→实施方案→获得证据或形成初步产品→分析证据或改进设计→得出结论或物化成果→表达交流展示"。

## 四、典型问题应对示例

> 以下 5 个示例逐一对照"从零写整篇教案""半成品补要素""导学案变体""情境化强化""板书反思专项"五种典型任务形态，均按【通用规范教案输出模板】的十二要素结构展开。**示例中的课标引用不可直接照搬到其他学科、学段或课题；具体引用按 SKILL.md 的来源规则核对，一般教案无需为填写条目号额外搜索**。

### 示例1【规范教案】小学语文《草船借箭》——任务形态：从零写完整教案

核心素养锚点：语言运用、思维能力为主，兼顾文化自信。教材分析：本课节选自古典名著《三国演义》，是一篇以人物对话和心理刻画见长的叙事性课文，按事情发展顺序记叙了周瑜为难诸葛亮、诸葛亮巧妙应对并借箭成功的完整过程；承接《景阳冈》等古典小说节选课文的阅读经验，为后续整本书阅读《三国演义》作铺垫；重点是通过品读对话把握诸葛亮"识人心、懂天时、用地利"的智慧形象，难点是理解借箭成功背后的多重条件（需要综合推理）。学情分析：学生已具备基本的默读圈画批注能力，但对军事、天文知识理解可能存在困难，对"诸葛亮为什么能借箭成功"这类综合推理问题有较高探究兴趣。教学过程采用"情境导入（三国背景+驱动性问题）→初读梳理情节→品读对话把握形象→整合推理突破难点→小结提升"五环节，每环节均配教师活动/学生活动/设计意图。板书采用提纲式，中央课题两侧分列情节脉络与人物形象。反思围绕目标达成、学情预判、情境效果、改进建议四问展开。

### 示例2【教案补要素】初中历史《鸦片战争》——任务形态：半成品补要素

用户提供了仅有教学目标和练习题的半成品，任务是补全教材分析、学情分析、各环节设计意图，**保留用户原有目标框架，不重新另起一套**。教材分析补全：本课是中国近代史开篇课，标志中国由封建社会逐步沦为半殖民地半封建社会的转折点，承接七年级"明清时期"学习，为"第二次鸦片战争""洋务运动"等后续内容奠基；难点是从具体史事上升到"社会性质转变"这一抽象结论。学情分析补全：学生对19世纪中英贸易矛盾、鸦片走私背景较陌生，容易简化因果关系；对"虎门销烟""火烧圆明园"等具体历史场景有较高情感共鸣，可作情境导入切入点。教学过程补全设计意图：环节一用历史情境（虎门销烟）引出驱动性问题；环节二史料研习梳理背景，落实史料实证；环节三历史地图识读落实时空观念；环节四史料辨析突破难点（从条约内容到社会性质转变的推理台阶）；环节五小结检测与用户原有练习题衔接。

### 示例3【导学案】初中数学《平行四边形的性质》——任务形态：导学案变体

用户要求产出"导学案+学习单+检测单"。处理方式：**先产出完整教师用教案作为底稿**（含课标依据、教材分析、学情分析、目标、教学过程等十二要素），**再将"教学过程"部分改写为学生自主学习视角的任务单**：课前预习单（画图+猜想）→课上学习单（任务一探究发现：动手测量对边对角对角线并记录规律；任务二尝试证明：连接对角线转化为三角形全等；任务三小组展示）→当堂检测单（性质应用计算题+开放猜想题）→学后反思（学生自评）。教师用教案与学生导学案的教学过程环节要一一对应，语言从"教师讲授"改为"学生任务指令"。

### 示例4【情境化教案】初中化学《燃烧与灭火》——任务形态：融入真实情境与学科实践

重点强化"真实性四检验"，情境素材优先选用课标官方推荐场景（家庭用电用气火灾、面粉厂/加油站/矿井防燃防爆）而非自行编造。教学过程：环节一用厨房/加油站火灾警示情境引出"燃烧到底需要什么条件"的驱动性问题；环节二分组实验（白磷红磷对比、热水冷水对比）落实控制变量的学科实践，突破"温度需达到着火点"这一学情预判中的认知薄弱点；环节三演示灭火实验后追问"破坏了哪个燃烧条件"，并迁移到面粉厂/加油站等真实生活场景讨论，完成情境"回收"闭环；环节四布置"家庭防火安全排查"真实任务作业。板书采用图表式突出"燃烧条件三角形"。

### 示例5【板书与反思专项】小学语文《为中华之崛起而读书》——任务形态：单独补板书/反思

用户单独要求补"板书设计"和"教学反思"两项要素。处理方式：**先简要给出完整教案上下文供核对一致性**，再重点展开这两项。板书设计思路：本课属于叙事性课文兼具"人物志向对比"核心线索，采用提纲式，中央突出课题，两侧分列"同学们的志向"与"周恩来的志向"形成对比结构，底部点出"中华不振"关键词，形成完整逻辑闭环（背景→情感→志向的因果链条）。教学反思按四问法展开：①目标达成——重点关注学生能否用"清晰、坚定"等词语准确描述语气变化而非简单复述原句；②学情预判——课前预判学生对时代背景陌生这一判断基本准确，背景资料补充后学生情感冲击明显增强；③情境/实践效果——对比朗读的语气区分度是检验理解程度的直观标志；④改进动作——背景资料呈现方式可从"教师讲述"改为"分层次出示图片+学生自己说感受"，板书可课堂中逐步生成而非提前写好，可增加"我为什么读书"小练笔落实情感目标的书面表达。
