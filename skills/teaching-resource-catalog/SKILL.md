# 教学资源目录

根据用户要找的资源类型和来源，检索希沃公共课件、教案，或教学资源库中的古诗文、微课、仿真实验、互动网页。本技能返回已有资源的检索结果和已知访问入口，不负责制作内容或把资源添加到个人云盘。

## 选择检索入口

优先遵循用户明确指定的来源，以及当前对话中已确定的资源范围；下表是没有其他限定时的默认选择。教材版本、年级、学科、作者是筛选条件，不等同于资源来源。

| 用户意图 | 入口 | 范围 |
| --- | --- | --- |
| “课件库”“希沃课件库”、找课件、公共课件 | `seewo_resource_library_search`，`type: "courseware"` | 希沃公共课件库，不是个人云盘 |
| 找教案、教案库、公共教案 | `seewo_resource_library_search`，`type: "teaching_plan"` | 希沃公共教案库，不是个人教案列表 |
| 古诗文、微课、仿真实验、互动网页 | 本 Skill 的类型目录及 `teachingResource.search` | 教学资源库的四类教学素材 |
| “我的课件”“我做的课件”“我的课件库” | `courseware_query` | 当前用户的云课件查询，具体范围以所选 action 的合同为准；参照 `seewo-en-courseware-management` Skill |
| “我的教案”“我写的教案” | `search_teaching_plans` | 当前用户的个人教案摘要 |

“课件库”通常指希沃公共资源库；“我的课件库”或当前个人云盘等明确个人范围时，按个人范围处理。用户明确指定公共库并要求查自己发布的资源时，仍查公共库，将作者作为筛选条件，不能确认时如实说明。用户明确指定现有教学资源库的课件时，仍可用 `teachingResource.search` 的 `resourceType: 1`；它不是普通公共课件检索的默认入口。用户指定多个类型或来源时，分别检索并标明来源；不因为某一入口结果少而自动切换到用户限定范围之外。

按用户要找的资源类型选择入口，而非只看课题或库名中的关键词：例如“古诗文课件”是公共课件，“《静夜思》的古诗文素材”是教学资源库中的古诗文；“在课件库找教案”使用公共库的 `teaching_plan` 类型。用户明确限定希沃公共库但要求微课等该工具不支持的类型时，说明该工具无法搜索所需类型，不静默换到其他来源。

用户只说“教学资源”而无法从上下文判断需要哪类资源时，先澄清类型；信息足够时直接检索，不为常见表述反复确认。

## 希沃公共课件和教案

1. 从请求或上下文提取课题或资源名称作为必填的 `keyword`；无法确定有效关键词时先询问，不凭空编造。选择 `type`（课件为 `courseware`，教案为 `teaching_plan`），从 `page: 1` 开始调用 `seewo_resource_library_search`。每页最多 5 条；需要更多候选时依据 `has_more` 按需续页。年级、学科、作者等条件不在该工具输入中，应根据实际返回字段核对；教材版本不作为独立字段返回，不能声称已按教材版本筛选。字段不足时说明无法确认，不声称未命中。
2. 搜索结果包含资源 UID、名称、缩略图、章节、作者和下载量等字段，部分字段可能为空；搜索不提供独立的年级字段。根据用户目标挑选候选；搜索不自动逐条查询详情，不为补齐每条记录而默认批量取详情。
3. 用户需要某条详情，或现有摘要不足以完成筛选、交付时，才对需要的候选调用 `seewo_resource_library_get`，传该结果的 `uid` 与 `type`。详情可能包含作者、缩略图、下载量、学段、学科、年级和章节，并返回对应的课件或教案 ID 和资源版本号；保留这些字段供结果展示或后续使用。详情不包含资源正文，不把元数据当成已阅读课件或教案内容。需要分析选中的公共课件内容时，可将详情中的 `courseware_id`、`courseware_version` 传给 `courseware_parse`；不对搜索结果默认批量解析。非个人课件不能使用 `courseware_read`，不能因为有公共资源 UID 或课件 ID 就将其当作个人课件；解析失败时也不能改用 `courseware_read` 兜底。
4. 检索结果标明来源为希沃公共资源库；如有缩略图及可用入口，按需展示。未返回分享链接或字段为空时如实说明，不拼接链接、不编造作者或资源 ID。

## 古诗文、微课、仿真实验和互动网页

这四类可先按需读取本 Skill 的精选目录，按用户的课题、学段和学科语义挑选；目录是部分静态索引，不代表完整或实时结果。

| 类型 | `resourceType` | 索引 |
| --- | --- | --- |
| 古诗文 | 3 | [古诗文索引](references/classical_literature/_index.md) |
| 仿真实验 | 2 | [仿真实验索引](references/simulation_experiment/_index.md) |
| 互动网页 | 4 | [互动网页索引](references/teaching_app/_index.md) |
| 微课 | 5 | [微课索引](references/micro_lesson/_index.md) |

目录未命中、候选不足、匹配不准确或用户要求线上搜索时，调用 `teachingResource.search` 并传入对应 `resourceType`。该工具的关键词只匹配资源名称，优先使用具体课题或常用名称；不要把整段需求拼成关键词。候选不足且 `ended=false` 时，保持条件按页续查，满足请求即可停止。

选定资源后，使用来自同一目录或搜索结果的 UID 和 `resourceType` 调用 `teachingResource.get` 获取详情与可分享链接。未返回链接时如实说明，不自行构造链接。`showCard` 默认关闭；仅在用户明确要求打开或使用资源，或最终选定少量资源作为直接使用入口时，对支持卡片的古诗文或互动网页设置 `showCard: true`。批量筛选、比较或为课件准备素材时不批量展示卡片。

## 调用与交付边界

- `teachingResource.search/get` 与 `seewo_resource_library_search/get` 是不同入口：详情使用搜索结果所属入口的配套工具，不假定两边的 UID 可以互换或仅凭同名判断资源相同。在 codemode 中按实际发现的工具声明调用；公共库 MCP 返回 `CallToolResult` 时先检查 `isError`，再读取 `structuredContent`。
- 只比较已取得且可比较的数据。搜索顺序或部分候选不足以证明全库下载量排名；未遍历全部匹配项时不要声称已列全。工具失败、未就绪或权限不足不是空结果，应说明未完成的范围，不自行改用其他来源冒充原结果。
- 返回资源名称、类型、来源及与需求相关的字段；缩略图、作者、下载量、详情 ID 和版本以实际返回为准。用户需要的字段不存在时如实说明。结果足以满足请求后结束；不因结果不足自行转为内容创作、资料编纂或文件生成。
- 用户需要在制作课件、教案或微课前查找四类教学素材时，按上述类型目录和工具流程检索，再将结果交回制作流程。该步骤不自动搜索公共课件或教案，也不执行下载、入库或其他写操作。

公共库的输入、返回字段和调用示例见 [检索入口与调用参考](references/resource_libraries.md)。
