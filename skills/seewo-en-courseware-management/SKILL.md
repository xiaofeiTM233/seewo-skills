# 课件管理

在原生 codemode 中调用下列 `tools.mcp__company_capabilities__…` 原生 MCP 工具，参数直接传结构化对象。参数和上限遵循当前可用工具合同，不自行添加排序、递归或其他未声明参数。需要核对合同时使用 `searchTools` / `describeTool`。返回原生 `CallToolResult`：先检查 `result.isError`，再从 `result.structuredContent` 读取业务数据。工具缺失时查询连接器状态并报告连接或鉴权问题，不尝试旧别名、自行 HTTP 请求或反复枚举全部工具。每次调用仍由 Host 校验授权、撤销和业务确认；写入结果未知时先查询或回读，不能自动重放。

不猜测资源 ID、链接或参数，不自行通过 HTTP 或其他路径绕过工具边界。

## 选择查询能力

根据用户需要的结果、资源范围和条件，优先选择能直接满足需求的能力。

| action     | 用途                           | 边界                                       |
| ---------- | ------------------------------ | ------------------------------------------ |
| query      | 跨目录读取课件明细             | 当前保留的个人普通课件，按更新时间或当前版本号倒序 |
| statistics | 全库数量、年度分布及代表性课件 | 六项固定统计，无业务筛选参数               |
| search     | 按名称查找资源                 | 名称匹配，资源范围以该工具合同为准         |
| list       | 浏览目录直接子节点             | 当前层读取，不递归，不提供全库排序         |
| tree       | 定位目录及了解层级             | 只含文件夹，受深度和节点裁剪限制           |

优先使用 query、statistics、search。list 用于目录浏览或必要核实，按需读取；不为“确保不漏”组合 tree/list 遍历全库，不用关键词穷举代替枚举。

完整读取全部课件须有明确任务依据，且更直接的能力无法满足。接口不足时说明缺口，不自动以全库扫描兜底。

目标目录已明确时，不先读取整棵树。query/statistics 不支持目录条件，不能代替指定目录查询；不同能力的资源范围不能混合计数。

需要分析某份课件内容时，使用独立的 `tools.mcp__company_capabilities__courseware_parse`，传入已核实的 `courseware_id` 和 `courseware_version`（个人普通课件或公共资源库课件；`courseware_version=0` 表示查询最新版本）；默认返回逐页文本、图片和视频链接。它读取已保存的云版本，不包含编辑器未同步修改；读取用户个人课件的编辑器状态、页面身份或截图使用 `tools.courseware_read`。非个人课件不能使用 `courseware_read`，解析失败时也不能改用它兜底。解析只覆盖部分元素，空结果或缺失链接不证明原课件为空，链接不等于已理解媒体内容。盘点或统计任务不自动解析每份课件。

## 条件与完成判断

query 只接受 updated_from、updated_to、order_by、limit、offset；order_by 可选 updateTime 或 version，省略时按更新时间倒序。statistics 只接受 action。

- 时间条件使用 Unix 毫秒，区间为 `[updated_from, updated_to)`。相对时间固定一次基准时刻，各页复用同一窗口；业务时区为 Asia/Shanghai，区分滚动时长与自然日。
- 优先使用服务端排序和汇总。已有摘要足以回答时，不读取明细重新计算。
- 版本号 Top N 使用 order_by=version，取够 N 份即停止，即使 has_more=true；N 大于每页上限时按原始页长续页。时间窗口仍按最近更新时间筛选，版本号不是窗口内修改次数。
- 本地筛选时保持服务端顺序。所需顺序与服务端一致时，累计足够匹配结果即可停止；采用其他排序或要求精确统计时，需要覆盖相应范围。
- 存在性判断取得命中即可完成；确认不存在、返回全部匹配或计算范围内极值，需要相应的完整性依据。
- 可对已有汇总做有依据的筛选或合并，但全库极值不能代替筛选范围内的极值。
- 达到工具上限或任务预算时，保留结果并说明覆盖缺口，不擅自改变条件后宣称完成。

## 分页与结果累积

- **query**：依据 has_more 继续，下一页按 offset 加本页原始 items.length 推进。
- **list**：从 page=0 开始；完整读取时，非空页继续，成功空页才结束。不依据短页、total、hasNext 或 has_more 判断完成。
- **search**：先保留本页结果；原始条数小于 limit 时结束，满页按原始条数推进。

保持读取范围、条件和分页规格一致。按资源 ID 累积去重，但不使用筛选或去重后的条数推进分页。跨调用用 store/load 保存候选、条件和进度，不覆盖已成功取得的结果。

错误不是空页。失败时保留结果及失败位置，不吞掉同类错误继续扫描。tree 的 truncated=false 也不能证明目录覆盖完整。

## 数据口径

- total 是当前保留的普通个人课件数，不是历史累计创作量。
- yearly、earliest_created 按客户端创建时间；latest_updated 按客户端更新时间，不能称为首次云端入库或实际使用起点。
- yearly 只返回有记录的创建年份；缺失创建时间的记录仍可能计入 total，不要求年度合计等于 total。
- highest_version.version 是当前版本号，不是准确编辑次数或现存历史版本条数。
- 夜间记录直接使用后端 preparation_date 和原始 updated_at。06:00 为备课日分界，不再次减六小时。
- 这些时间不能证明服务端保存完成、完整历史活动或连续工作时长。
- 缺失时间、合法负时间戳和 null 如实保留，不补当前时间。统计和分页不承诺事务快照。
- 名称匹配不证明正文内容，同名不证明重复。

## 管理操作

使用 `tools.mcp__company_capabilities__courseware_manage`，通过 action 选择操作：

| action        | 用途             | 关键参数                |
| ------------- | ---------------- | ----------------------- |
| create_folder | 创建文件夹       | name、parent_folder_id  |
| move          | 移动课件或文件夹 | items、target_folder_id |
| rename        | 重命名           | resource、new_name      |
| delete        | 删除课件或文件夹 | items、recursive        |

items 中每项使用 `{id, type}`，resource 同样使用 `{id, type}`；type 为 courseware 或 folder。删除项应携带查询得到的 parent_id，供服务端核实所在目录。

parent_folder_id、target_folder_id 为空字符串时表示根目录。必填项、默认值和上限遵循工具声明。

只处理用户已授权且目标明确的资源。ID、类型和目录来自查询结果；存在实际歧义时先澄清，不自主创建目录或扩大清单。

- **create_folder**：用户明确要求创建时执行。
- **move**：核实资源清单和目标目录；未明确授权具体清单的批量操作，先确认范围。
- **rename**：课件改名会生成新版本，执行前说明影响；文件夹改名不产生课件版本。
- **delete**：只调用一次删除工具。Host 通过同一 Pi 连接读取实际删除预览，并请求一次用户确认；批准后执行，不自行获取或传递确认 token。recursive=true 包含执行时目录内的全部内容。预览失败、拒绝或取消不执行；派发结果未知先回读核实，不自动重放。

descendant_count 仅统计文件夹节点并包含自身，不能当作课件数量或据此判断目录为空。

Host 统一绑定实际预览和用户审批，服务端继续复核资源与权限。写入已派发但结果未知时先回读核实，不自动重放；operation_id 不是幂等保证。

## 异常与交付

- 参数错误：依据工具声明修正，不试探未声明参数。
- 登录失效或权限拒绝：停止相应操作并说明阻塞。
- 协议、结果编码或未知派发错误：停止当前批次，保留结果和进度。
- 只读临时失败：仅在工具明确允许时最多重试一次，再次失败即停止。
- 业务拒绝：按实际原因处理，不统一解释为登录失效。

有足够依据就及时回答，按用户需要展示字段、范围和影响结论的缺口，避免反复输出完整 DTO。已有资源不作为本次生成的产物发布。

区分完成、部分完成和未完成，不把工具成功或脚本结束单独当作用户目标完成。
