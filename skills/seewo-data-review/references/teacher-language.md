# 面向老师的数据用语

取数时可以使用系统字段；写进 H5 前，必须换成老师日常会说的话。准确比术语完整更重要。

## 固定替换

| 取数或系统说法 | H5 中的说法 |
| --- | --- |
| 云端根级资料、根级条目、根目录条目、条目 | 云端资料 |
| 微课工作台、工作台 | 微课 |
| lesson_count、已出课 | 已生成的微课 |
| 本地文件、本地文件夹 | 本地资料 |
| 目录树、父目录、子节点 | 分类、文件夹 |
| 根目录散件 | 还没分类的课件 |
| 未关联班级、接口无班级 | 班级学情暂时还没有数据 |
| updated_at | 最近更新、最近一次保存或调整 |
| created_at | 创建时间、在云端留下记录的时间 |
| version | 云端版本、留下的版本记录 |
| 素材、源内容、素材表征 | 用来制作微课的资料 |
| plan、courseware | 教案、课件 |

## 首屏经历回顾的写法

经历回顾卡让老师回望自己的经历，按「选经历片段 → 写共鸣短句 → 提炼共同主题」组织内容。

- **选片段**：从本轮材料中选取最有分量的 3–4 个具体经历，可关注陪伴、持续准备、学习变化或阶段完成，围绕这些经历形成一条共同主线。
- **写短句**：用作品、一届学生、一个课题或一次阶段变化作为锚点，写出其中的过程或关系。时间与数量有助于唤起回忆时自然带出，具体统计在后续正文展开。
- **定主题**：从片段共同表达的经历中凝练中心短句；有明确含义的数字也可以成为主题，例如材料明确记载三年陪伴时的「3 年 · 一路同行」。

以下示例展示提炼方法；生成时根据本轮实际材料选择角度和措辞。

| 材料依据 | 共鸣短句示例 | 提炼的过程或关系 |
| --- | --- | --- |
| 持续带同一届学生，目前已到九年级，材料确认从七年级开始带班 | 这一届，从七年级一路陪到现在 | 同一届学生与持续陪伴 |
| 读到了多年前保存的备课材料 | 当年的那份准备，今天翻开还能看见 | 过去的准备与今天的回望 |
| 课题材料记录了多个推进阶段，并已收尾 | 那项一步步做过的课题，终于走到了收尾 | 持续推进与阶段完成 |
| 同一份课件近期有多次具体调整记录 | 最近这份课件，还在一点点打磨 | 一份具体作品与持续调整 |

主题与共鸣点相互呼应，读起来像对自己经历的自然回望。材料不足或不适合时省略整个区域，沿用技能正文的展示条件。

## 时间线表达

「我一路做过的事」把本地经历与云端记录写在同一时间轴上：

- 先写这一阶段真实发生的事；
- 再写同一时期云端留下的课件、教案；
- 节点以事实结束，不附加情绪连接或总结句。

可用句式：

- 「第一份希沃云课件创建于 YYYY 年 M 月 D 日 HH:mm，课件名：《名称》。」
- 「这一年，云端留下 X 份课件、Y 份教案。」
- 「按现有云端版本记录看，《名称》是反复调整最多的一份，留下了 X 个版本。」
- 仅当本地时刻严格晚于 22:00：「现有云端记录里，忙到最晚的一天，制作的是《名称》课件，忙到了 HH:mm。」

不用句式：

- 「这一年没有制作课件／教案。」
- 「第一次备课是在……」
- 「这份课件被上过很多次。」
- 「没有熬夜记录」「最晚只到 21:30」「作息很规律」。
- 不带「现有云端记录里」限定的绝对最晚结论。

情绪来自真实细节：具体年份、作品名称、版本积累、较晚的保存时刻。本地与云端要共同讲同一段经历，不能写成两份资产清单。

## 近半年更新的说法

时间和完整性按 [近半年更新分析](recent-courseware.md) 处理。课件最近更新时间不是修改次数或授课时间；每份只按最后一次更新时间归入一个月份。

- 完整读取：「从 YYYY 年 M 月 D 日到 YYYY 年 M 月 D 日，共有 X 份课件留下了最近更新记录。」
- 未完整读取：「这次先看到最近更新的 X 份，时间从……到……，近半年资料尚未完整读取。」不将 X 写成半年总量，也不把没读取的月份写成 0。
- 最近作品：「最近这些课件涉及……，其中《名称》最近更新于……。」名称不能证明正文内容，不把近期样本写成全部教学工作的学科构成。
- 版本较高：「本次看到的课件里，《名称》当前版本号较高，可优先回顾。」不能写「半年改了 X 次」或把版本号作为工作量。
- 完整成功且为空：「这个时间范围内暂无更新课件。」不据此评价老师半年没有备课。
- 目录名称只辅助解释路径；不以目录 total 推断份数、分类占比、缺少某类资料或应该删除同名作品。

## 每年代表课件的说法

按 [每年代表课件分析](annual-courseware.md) 每年读取前 20 份，再选 1–3 份有依据的代表作品写入同一年份卡片。按当前最近更新时间归年，跨年更新的课件不能据此还原以前的活动。

- 可用：「这一年最近更新的课件中，《名称》留下的云端版本记录较多，可作为这一阶段的代表作品回顾。」
- 主题比较只说「这些代表作品涉及……」，不推断全年学科占比或工作量；没有正文依据时保留名称层面的判断。
- 时间线附近解释一次：「这些作品按最近一次更新时间归年，参考当前云端版本记录挑选，不代表当年的修改次数。」
- 不写「每年更新最多」「这一年修改了 X 次」或「当年最常使用」；未完整取得的年份只称「本次取得的代表作品」，失败不写成 0。

## 数字与单位

- 本地资料：用「件」或「份」。
- 云端资料：用「份」，不用「条」。
- 微课：统计各清单项 lesson_count 的总和，用「节」；不要把工作台数量当作微课数量。
- 尚未生成微课的内容：写「还有 X 份资料尚未生成微课」，不要写「X 个工作台未出课」。
- 班级陪伴时间：用「年」，标签可写「陪伴这一届」。
- 某年课件或教案为 0 时省略对应数字，不用 0 推断老师没有备课。

## 禁用用语

生成 H5 时直接使用上面的日常用语，不写以下词；不另起自检或回到取数结果重新翻译：

「根级」「条目」「工作台」「接口」「目录树」「父目录」「节点」「lesson」「素材表征」「trace」「状态码」。

判断标准：老师不需要知道数据从哪里取来，只需要看懂自己有什么、最近做了什么、下一步做什么。
