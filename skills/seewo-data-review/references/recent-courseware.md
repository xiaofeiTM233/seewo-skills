# 近半年更新的课件

这部分回答「最近半年还在更新哪些课件、最近在准备什么」，不读取课件正文、不遍历目录。使用当前保留的个人普通课件及其最近更新时间，不把它解释为完整创作或授课历史。

## 取数与复用

1. H5 运行开始时执行一次 `store("seewo-data-review:recent-courseware", null)`，清除上一轮回顾的取数缓存；本轮之后不再重置。待办运行不执行这一步。
2. 读取 `scripts/collect-recent-courseware.js`，将正文作为 codemode 代码执行，不用 Shell 执行、不改写分页循环。它通过 `tools.mcp__company_capabilities__courseware_query` 直接取数，最多 5 次请求、500 份原始记录。
3. 时间窗口按 Asia/Shanghai 固定为当前时刻往前推 6 个自然月，保持同日同时；目标月没有该日时取月末。区间是 `[updated_from, updated_to)`，各页使用同一窗口。例如 10 月 20 日 09:00 对应 4 月 20 日 09:00 至当前；8 月 31 日往前推到 2 月最后一天，不用 180 天代替。
4. 脚本以原始页长推进 offset、按真实 id 去重，每页保存成功结果，失败立即停止。再次执行只返回同轮已有结果，不重新请求。不要另开 query 读取「最近 20 份」；摘要中的 recentExamples 已覆盖这项用途。
5. `coverage.complete` 只在 has_more=false，且没有重复、无效或越界记录时为 true。达到页数上限、错误、空页却 has_more=true，均保留样本并说明未完整读取。不得切换到 list/search、按月份切窗或改分页参数绕过预算。
6. 出现限流时暂停本轮同一 MCP 的其他可选读取，保留已取得的数据；不立即改查另一业务、不热重试。不把未取得的微课或教案数据写成 0。

摘要包含窗口、完整性、已读数量、实际覆盖时间、最近 20 份课件和当前版本较高的 3 个例子；完整读取时才包含月度分布。全部已读明细保留在 `load("seewo-data-review:recent-courseware").items`，需要核对名称时按字段投影，不截断 JSON 字符串，不为了取回已读字段再请求接口。

## 分析口径

- **近半年更新课件数**：只在 complete=true 时使用 updatedCoursewareCount。每份课件按 id 计一次，按最后更新时间归入一个月份；不是更新事件数，也不是新增课件数。
- **按月分布**：只使用完整结果中的 monthlyLastUpdates，标签为「按最近更新时间分月」。窗口跨两个不完整自然月时标明首尾月份只覆盖部分日期，不按数量大小评价忙闲。不完整结果不生成半年趋势图，也不把未读取月份填成 0。
- **最近作品**：从 recentExamples 按返回顺序选择 3–5 份，展示名称、最近更新时间和有依据的教学主题。日期转为北京时间；没有足够作品就少写，不补示例。
- **近期主题**：依据已读名称和已有真实材料描述，不用文件夹名称或部分样本计算全库学科占比。仅看了 recentExamples 时写「最近这些课件涉及……」；名称不足以判断内容时保留未知，不声称读过正文。
- **版本较高的作品**：higherVersionExamples 的 version 是当前版本号，只用于指出值得回顾的作品；不能写成「半年修改 X 次」「半年最常修改」。比较范围明确为「本次读取的课件」。
- **下一步建议**：连接最近作品与已核实的需求，例如回顾一份近期更新的课件、为明确主题准备后续材料。没有读过相应目录或正文，不能断言缺少练习、同名为重复、应删除旧版，或某单元已经齐备。
- **与历史总览分开**：全库 total/yearly/极值来自 statistics，不要求半年样本数量或月度数量与全库 total 相等。局部明细不完整不影响有效的全库统计。

## H5 展示

在「我的家底」之后、「我的工作重心」之前加入「近半年更新的课件」，并让工作重心和 TOP3 引用这部分证据。

- 完整读取：展示明确起止日期、「近半年更新 X 份」、按月最后更新时间分布、3–5 份最新作品、近期主题及依据。
- 达到预算或分页不一致：标题或紧邻说明标明「近期更新样本」，展示「已读取 X 份，覆盖 YYYY-MM-DD 至 YYYY-MM-DD；近半年资料尚未完整读取」；不展示精确半年总数、半年比例或半年月度趋势。
- 中途查询失败：说明读取不完整并保留已有作品；没有成功数据时只说「这部分暂时没有取得」，不补零。
- 成功完整读取且为空：可以写「这个时间范围内暂无更新课件」，但不能写「半年没有备课」。

模板中的数量、日期和作品名称都是占位内容，交付时必须替换或省略。面向老师只展示日期、范围和结论，不输出分页、预算、错误码或工具名。
