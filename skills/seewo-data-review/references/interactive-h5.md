# 把盘点做成一份互动 H5

## 固定内容

- 文件名：**「希沃一刻 · 我的沉淀.html」**。
- 顶部标识：**「希沃一刻 · 我的小数据」**。
- 主标题：**「盘一盘这些年的沉淀」**。
- 首屏标题与副标题无主语，不写「我把……」。

## 两轮顺序

### 运行 A：H5

1. 数据连接、我的资产、近半年更新的课件、工作重心、TOP3 待办全部写入单文件 HTML。
2. 用 content.json 和 scripts/render-report.mjs 按固定文件名生成，不复用旧 HTML。
3. 渲染写入成功后立即调用宿主 `publish_file`，path 指向本轮实际写入的 HTML，summary 一句话说明资料回顾、近半年更新与下一步建议；不插入任何校验、预览或修改。工具返回成功后作为正式产物交付；这只登记本地文件，不上传、不分享。登记后结束本轮，**禁止调用 ask_user**。
4. 登记失败或工具不可用时保留已生成文件，说明尚未登记为正式产物，不通过重写文件、拼接链接或打开浏览器冒充成功。

登记成功后的最终对话回复按[技能正文](../SKILL.md)给出交付说明，以「下一步三条（与 H5 一致）：」列出与本轮 H5 标题原文及顺序一致的三条待办，并以「想直接动手，说一句『继续』就好。」收尾。列表复用生成 H5 时的内容，用户后续发送「继续」时进入运行 B。

write/edit 或渲染脚本只产生本地文件；publish_file 成功表示正式产物已登记，仍不代表界面已经展示。不等待或轮询猜测展示完成，不在本轮弹待办卡。

### 运行 B：待办

老师在后续消息说「生成待办」「继续」「下一步」「选一条」时，直接调用一次 `tools.ask_user` 的 select 单选卡，选项为与最近 H5 完全一致的三条待办原文及「这次先不做」，关闭自定义答案。等待实际选择后推进选中的一条；选择「这次先不做」或取消即结束。老师已明确点名其中一条时，直接推进。

## 生成即交付，严禁校验

以下内容和视觉要求直接用于生成，不形成独立检查阶段。

- 禁止执行自检、机械检查、内容复核、文件回读、浏览器预览检查、截图、裁图、读图、布局检测或测试。
- 不把检查前移为写入前的独立步骤，不重新查询数据复核文案，不因检查追加修改或重写。
- HTML 渲染写入成功后直接登记交付；不声称内容、交互或版面已经验证。

以上约束适用于每次报告生成；模板维护阶段的适配验证由开发流程承担，不增加报告运行中的取数、复核或交付步骤。

## 内容顺序

1. 首屏：品牌绿色数字资产沉淀主题头图、标题、说明；头图下为可选的独立经历回顾卡，遵循[首屏经历回顾](../SKILL.md#首屏经历回顾)。有合适证据时呈现一个主题和 3–4 条共鸣点；材料不足或不适合时省略整张经历回顾卡，不保留占位；品牌装饰头图不受影响。
2. 关键数字：本地资料、云端资料、微课、陪伴这一届。
3. 真实时间轴：本地经历与云端课件／教案记录统一编排。
4. 云端与本地家底。
5. 近半年更新的课件：日期范围、完整性说明、最近作品与近期主题；完整读取时增加半年更新份数和按月分布，遵循 [近半年更新分析](recent-courseware.md)。
6. 工作重心与证据。
7. TOP3 待办。
报告以 TOP3 待办卡片结束，不追加结尾总结或交付提示。

## 「我一路做过的事」

保持当前章节位置，年份按单列竖向时间轴排列，使用品牌绿节点与细线串联，每个阶段下直接呈现分点事实，不新增独立数据章节。只把真实课件／教案时间嵌入现有本地经历。

- 本地事件是主叙事：带班、课题、培训、代表成果等必须来自真实材料或可信记忆。
- 云端时间是同一阶段的补充证据：按创建年份写该年新增课件数；有教案时补充教案数。
- 按 [每年代表课件分析](annual-courseware.md) 将各年已取候选中的 1–3 份作品融入同年卡片，用名称和真实材料辅助解释阶段主题；不铺满 20 份，不新建第二条时间线。时间线附近说明一次「按最近一次更新时间归年，参考当前版本记录挑选，不代表当年的修改次数」。
- 每个节点依次写「这一阶段做什么 → 云端留下什么」。不能拆成两条时间线或两份清单。
- 同一年份或阶段有两项及以上关键事项时，使用一个直接显示的分点列表：每个事项独占一行、前置克制小圆点，不用逗号或分号压成整段。
- 每个事实点只承载一类信息：带班变化、课题节点、代表成果和年度云端新增分别成点；本地经历在前，云端记录在后。不附加情绪连接或总结句。
- 仅有一项事实时可以保留普通短句；不为凑点拆碎同一事件，也不把长句靠手动换行伪装成列表。
- 推荐结构：节点标题使用年份；事实使用 ul/li。列表点间距约 7–10px、行高 1.55–1.7，卡片高度自然撑开。
- 第一份课件使用真实最早创建记录：
  「第一份希沃云课件创建于 YYYY 年 M 月 D 日 HH:mm，课件名：《名称》」。
- 版本最多的课件仅在最大版本号大于 1 时展示：
  「按现有云端版本记录看，《名称》是反复调整最多的一份，留下了 X 个版本。」
- 最晚保存只比较课件有效更新时间；严格晚于 22:00 才展示：
  「现有云端记录里，忙到最晚的一天，制作的是《名称》课件，忙到了 HH:mm。」
- 22:00 及之前省略整条，不显示空位、替代文案或作息评价。
- 某年课件为 0 时不写「0 份」，该年仍有本地事件就只写本地事实；两边都无证据则不生成节点。
- 云端某项时间或版本字段无效时，只省略该项结论；半年明细不完整不影响 statistics 中有效的历史代表记录。没有云端证据时保留真实本地时间线。
- 节点只展示真实事实，不增加独立感想。

年份多时仍保持单列竖向时间轴，桌面和手机均按时间顺序从上向下阅读；节点高度随内容自然撑开，不固定高度、不截断，连接线只串联相邻节点，不增加横向滚动。

## 固定视觉与布局

- 和设备巡检、校情报告使用同一视觉规范：品牌绿 #00C881、浅绿背景 #F0F8F4、白色正文卡片，边框 rgba(0,0,0,.14)。不使用旧版暖米白、深棕、朱砂红和宋体样式。
- 头图横向铺满、顶部无留白，文字垂直居中；云端课件、数字教案、微课与数据记录配图保持在右侧，以长距离透明遮罩自然融入背景。手机隐藏装饰配图。
- 正文最大宽1080px，上叠头图32px（手机24px）。每章独立一张白色大卡片，32px圆角、四边32px内边距，卡片间距16px。
- 章节内部区块间距24px，内部卡片16px圆角、16px内边距、16px间距，文字细节8px。手机大卡片四边24px、区块16px；不固定卡片高度，不通过裁切或隐藏溢出掩盖长内容。
- 中文主标题32px、章节标题18px、正文14px；大号数据与章节序号使用内嵌 CCtype Medium（500），中文使用无衬线字体。数字单位与数值间隔4px。
- 时间线按时间顺序使用自然撑开的卡片；桌面两列、手机一列，不强行每章占满一屏。
- 正文只需滚动即可读完，不增加固定锚点导航、计数动画或依赖 JavaScript 才显示的内容。

## 生成入口与固定资产

按 [report-content.md](report-content.md) 写入 content.json，然后调用：

```sh
node <技能根>/scripts/render-report.mjs --data <content.json> --out "<本轮唯一目录>/希沃一刻 · 我的沉淀.html"
```

`assets/h5-template.html` 为固定外框；`report-base.css`、`report-hero.css`、`report.css` 按顺序原样内联。字体与头图均内嵌，离线可读。运行态不依赖其他 skill 或归档目录，不自行覆盖颜色、字体、圆角、布局。

渲染后立即沿用运行 A 的登记交付流程，不插入真实报告校验。只有维护模板时才用 mock 数据验证宽屏、窄屏、长文字、缺少可选章节和无脚本阅读。采集脚本及其年度/半年数据口径不变。

## 内容与交互底线

- 全部正文、依据与待办直接显示，不使用折叠、悬停揭示、问卷或资源跳转。
- 统计数据只来自本轮已取结果；未完整读取时不画半年分月图、不把样本写成总量。
- 可选回顾卡没有证据时直接省略，不保留示例、空占位或固定高度。
- 年度事实按分点列表呈现；原有时间线取数与写作规则继续适用。
- TOP3 待办原文与后续对话选择一致，本轮不提前执行待办。
