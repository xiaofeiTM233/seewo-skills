# 希沃白板课件

使用当前技能内的参考完成希沃白板课件任务。个人风格来自当前有效记忆或本次授权的材料。新课件创建新作品，同名课题先检查已有目录并选用无冲突的课题目录。继续制作或编辑时先核对已有作品和进度，沿用实际记录的源稿路径。

## 个人风格承接：制作必经步骤

新课件仍先执行下文教材联网核对；随后在教学内容编排、教案生成、风格选择及 STORY/DESIGN 规划之前，必须阅读并执行 [个人风格读取、落实与验收](references/personal-style.md)。完整识别当前有效的适用规则，而不是只读画像标签；主题、规范文件读取不完整时不可报告完整承接。

承接链为：当前有效记忆索引 → 适用主题全文 → 主题引用的完整规范 Markdown（适用规则、例外、状态和验收章节）→ STORY/DESIGN 中的规则落点 → 共享样式和真实页面 → 全篇内容核对及代表页视觉检查。读取规范的全部适用规则，必要时分页；无关原始证据可按需读，不每次重跑风格提炼或重读原课件。

当前明确要求优先；在科学性、可读性、隐私权限和真实工具能力边界内，适用且已确认的个人规范约束通用默认设计，默认设计只补足未限定部分。本文及配套资料中「主动变化配色」「自由构图」「四套方案」均以先完成个人风格判定为前提，不能抹去有效的个人颜色语义、栏目、页型、问题路径或答案揭示。存在影响任务的冲突先说明或按需提问，不静默覆盖。记忆关闭、文件缺失或范围不匹配时遵循该参考中的降级与告知要求。

仅要求创建、修改或诊断本技能时，不启动风格提炼、课件生成或个人记忆保存。

## 学科专业能力协作：制作必经步骤

物理、化学、生物等课件在 STORY 识别专业图示需求时，阅读并执行 [学科专业技能接入](references/subject-integration.md)，按图示任务和当前可用技能匹配。静态 SVG 使用当前会话可用的转换方式得到 PNG，核对后插入。工具发现和旧客户端回退按该参考执行。本技能负责整课教学、个人风格、页面组织与 EN 交付。专业技能负责其覆盖范围内的图示生成和专业检查。

物理的电路、受力、磁场、光路、实验结构、物理数据图等，按 [物理教学图接入与验收](references/physics-integration.md) 执行 seewo-physics-illustration 的真实生成流程：模型核对 → 专业绘图与导出 → 实际图像审阅 → 真实素材登记 → 插入对应页 → 接入验收。只读规范、只生成源码或使用普通 diagram/生图，不算完成该技能生成。分步揭示使用专业技能生成的分层/状态素材；连续调参的 SVG/Canvas 由页面按明确模型实现，不冒称专业技能具备动态仿真能力。依赖不可用时按接入规则保留缺口，不静默替代。本技能仍只负责 EN 及其嵌入 HTML，独立网页与微课由各自主流程承接。

## 最终产物与过程文件

最终产物为本次创建或编辑的 EN 课件，以及过程中通过 `seewo-lesson-plan` 生成的完整教学设计／教案；教学设计／教案沿用自身交付规则。复用已有教学资料只是在准备输入，不将其登记为本轮新成果。

除上述成果外，`STORY.md`、`DESIGN.md`、风格预览片段 `style-options-inline.html` 及降级预览 `style-options.html`、批次草稿、TSX、互动页 HTML 源稿、配图、截图及校验记录均为过程文件。风格选择优先按 [生成与风格选择](references/workflow.md#四套风格预览) 使用当前可用的 `visualize` 技能在消息流展示；其他过程文件需要时通过已核实路径的普通文件链接预览，不调用 `publish_file` 将它们登记为最终产物；互动页随 EN 课件整体交付。

所有页面（封面、章节、原生讲解与 HTML 互动页）统一不添加固定页脚、页码/总页数、重复的教材版本或课程署名栏，也不把它们改放在页眉、角标中。页序保留在 STORY、工具元数据与编辑器导航中；必要出处就近标在引用或图片旁，完整来源放备注或交付说明。页面标题直接表达本页问题或内容，避免无意义的章节编号、英文眉题和口号式文案；保留有教学意义的题号、操作步骤与互动控件。具体见 [主题与页框](references/design.md#主题与页框)。

## 新课件先搜索教材

收到具体课题的新课件任务后，读取本 Skill 的首个任务操作是调用可用的联网搜索工具（如 `web_search`），核对该主题在当前已投入使用的新版教材中的章节与实际内容。此操作必须早于读取制作参考、调用 `ask_user` 选择课时范围或规划课件；不要先用旧版节次提问，等用户纠正后才搜索。首轮搜索只用用户已给出的主题、学科、年级、地区、出版社和“新版/最新”，**不加入未经核实的章节号，也不擅自指定出版社**；已确认新版出版或修订年份时再加年份。搜索不可用时，除非用户明确要求，不要立即重复相同搜索或切换线路重试。比较候选教材版次，默认采用当前已投入使用的最新适用版；优先核对用户当前教材、出版社或教育主管部门资料，官方课页不可得时用标明新版版次的教辅资料交叉核对。多个出版社或版次仍影响内容时再问实际用书，教学范围选项只能使用已核对的新版节次。搜索不可用或无法核实时，请用户提供封面、目录或对应课页，不声称已核实。仅修改已有课件的版式、文案等不涉及教学内容时无需重新搜索。

## 补充资源按需检索

课件制作默认不读取 `teaching-resource-catalog` 的类型索引，不逐类核对古诗文、微课、互动网页、仿真实验，也不主动调用 `teachingResource.search` 或 `teachingResource.get`。未检索补充资源不阻塞页面规划与制作，无需在交付说明中列出未补充的资源类别。仅当用户明确要求查找或补充上述资源时，按 `teaching-resource-catalog` 技能执行，使用工具返回的真实资源链接，不伪造或拼接链接，也不执行入库操作。

## 调用课件能力

非个人课件（包括公共资源库课件）不能使用 `courseware_read`；即使已知课件 ID，也不能把公共资源当作个人编辑器课件。需要分析公共课件的已保存内容时，使用公共资源库详情中的课件 ID 和版本调用 `courseware_parse`；解析失败时不要改用 `courseware_read`。

1. 在原生 codemode 中调用 `tools.courseware_lifecycle`（创建或重命名）、`tools.courseware_read`（查询）、`tools.courseware_edit`（修改）或 `tools.courseware_present`（呈现）。需要发现或核对参数时，在 codemode 内使用 `searchTools` / `describeTool`；操作 `kind` 以当前声明为准，不猜相近名称。
2. 参数直接传结构化对象，工具直接返回业务 DTO。截图读取 `reply.images` 和 `reply.reviewEvidence`，审阅状态读取 `reply.slides`；不同查询分支按实际字段判断，不将缺失字段当成空结果或零。批量内容修改参见 [编辑](references/editing.md)，不要将独占动画操作混入普通修改数组。
3. Host 保留真实业务回执和产物；截图使用 `image(reply.images[0])` 显式输出对应图片，再等待后续模型请求实际收到图片后提交审阅。只 `print` 必需的新计算或筛选结果；未知写入先核对实际状态，不为恢复数据重放写入。

以准确、完整的教学内容和统一视觉规范指导页面，模型自由组合图文，工具编译为可编辑的 EN 元素。在 STORY 阶段就逐页确定互动、动画和教学配图，与内容一起制作。按当前阶段读取下方参考，不在教学准备时预读全部布局与审阅规范。规划时按 [教学动画](references/animations.md#场景与节奏) 确定具体分组和效果，首次原生页写入前核对其生成参数，不把动画留到全篇完成后临时补选。

## 教学准备

准备阶段只补齐尚缺的信息：教材版次、范围和必须引用的原文核实后复用来源，不继续重复搜索同一结论。当前阶段需要的参考与工具声明集中读取，已读且无变化的不重复读取或 describeTool；动画场景在 STORY 规划时确定，布局与动画参数在首次制作前核对，审阅参考在检查前读取。STORY、DESIGN 和共享结构只准备一次，素材随首批需要获取，尽早进入首批3–4页制作。下述教案及风格确认仍按用户已有选择执行，不增加额外确认。

已有教学设计也要确认其教材范围与当前任务一致；选择直接制作同样执行上面的教材核对。向用户简要交代采用的教材版次、课题范围和来源。

已有适用教学设计直接承接；没有且用户只要求课件时，用 ask_user 询问“是否先生成教学设计再制作课件？”，提供“先生成教学设计（推荐）”与“直接制作课件”，等待选择。用户已明确选择时不重复询问。

选择先教学设计：按 seewo-lesson-plan 的方法组织完整内容；桌面端具备教案工具时，将完整 Markdown 直接作为 `tools.teachingPlan_lifecycle` 的创建参数，创建一份 EN 云教案并展示给用户审阅。Markdown 仅作为工具输入，不先写入或发布 `教学设计.md`、`教案.md` 等本地中间稿或副本。后续意见在返回的同一 `planUid` 上读取当前版本并局部修改，不重新创建文档；交付只引用这一份云教案。具体参数、保存与异常处理遵循 seewo-lesson-plan 的教学文档交付规则。提供可打开的完整教案链接或预览，并在对话中呈现教学目标、重难点、教学流程与关键活动、练习和评价的内容摘要；不能只告知文件已保存。宿主无法展示文档时，在对话中展示完整教案，可按章节分段。

创建前确认当前环境具备云教案创建、读取和编辑能力；缺少必要能力时，降级为 Session 工作区 `en-courseware/<课题短名>/教学设计.md`，展示该文件并在同一文件上继续修改，只交付这一份本地教案。不得把一次调用失败或结果未知当作能力缺失；异常恢复遵循 seewo-lesson-plan 的规则。

展示后用 ask_user 询问“这份教案是否符合预期？确认后我再制作课件。”，提供“确认，开始制作课件”与“需要修改教案”两个选项，并允许用户填写具体意见。等待用户确认当前教案内容后才进入制作流程；选择先生成教案不等于确认教案内容。用户要求修改时，先更新文档、展示修改后的内容与完整教案入口，再请用户确认。确认前不展开页面构图、风格选择或创建 EN 课件；没有 ask_user 时用文字询问并等待回复。

选择直接制作：组织必要目标、活动和完整题目，不另写完整教案。仅编辑已有课件直接进入 [编辑](references/editing.md)。

## 制作流程

按 [生成效率与恢复](references/workflow.md#生成效率与恢复) 合并独立准备、保留草稿、复用已有结果并局部修复。10 分钟仅用于衡量改进效果，用户等待另计，不设分阶段制作时限或临近截止的质量降级规则；不得为赶时间减少已规划的 HTML 互动、EN 原生动画、教学配图、主题装饰与必要验证。按实际配图缺口推进，普通插画在素材检索未命中时按[配图兜底](references/design.md#素材准备与复用)切换来源。

1. 阅读 [生成与风格选择](references/workflow.md)。基于教学内容完成必要澄清；视觉方向未明确时呈现四套风格选项：当前 `visualize` 技能可用时先读其规范，在消息流直接展示适配窄栏的方向示意，再用 ask_user 等待选择；缺少该技能时沿用 HTML 文件预览与选择流程。先用同一段教材内容展示不同的阅读顺序、图文位置与重点。主题可通过摄影、插画、推导或原文排版体现。展示之前，把网格、纹理、线稿等可见背景存成可复用图稿，并从该图稿渲染风格卡。用户选定后取回同一版本应用到对应页，见[四套风格预览](references/workflow.md#四套风格预览)和[主题矢量图稿](references/vector-graphics.md#主题矢量图稿)。用户指定净底、纯摄影背景或既有模板有明确背景规范时沿用其要求。四套方向由模型为当前课题独立设计，不读取内置样例，不声称示意已经原生渲染。明确风格、参考模板或要求直接出稿时跳过；已读到适用且足以约束方向的个人规范同样属于明确风格，不再展示四套通用皮肤，未限定细节直接合理补齐。
2. 写简短 `STORY.md` 与 `DESIGN.md`：前者按 [逐页规划表](references/workflow.md#story-与-design) 记录任务与必要内容、HTML 适用性与载体选择、具体动画、第一焦点及教学素材来源；后者承接用户参考或选定预览，单列[背景与装饰方案](references/design.md#背景与装饰方案)，写明本课背景或装饰的可见特征、正文落点和避让区。普通正文默认沿用所选方向的背景特征；图文或控件密集时先在同一图稿上调整摆位与强度，确需净底的页在 DESIGN 列为例外。封面图按用途归档。两者同时落实 [个人规则对应表](references/personal-style.md#规则进入-story-与-design)，记录来源、适用状态、页面或元素落点及验收方法，不以风格名称替代具体要求。阅读 [视觉设计](references/design.md) 和 [视觉层级与密度](references/visual-rules.md)，区分讲稿与上屏内容，不计算逐页字数、填充率或留白配额。首批直接取回被选中的完整 CoursewareDesignSpec，用在 STORY 中安排的代表性正文页，用 createCoursewareDesign 将配色、文字角色、富文本强调与背景落实到原生 page，并导出 HTML 使用的 CSS 变量；标题与批注构图用本课纯函数复用，见[整套视觉规格与原生复用](references/design.md#整套视觉规格与原生复用)。有明确重点的正文默认使用[原生富文本](references/design.md#正文富文本与重点标注)标注概念、条件或证据词，上下标按语义使用；推进、对照或归纳优先用[原生箭头与标注图形](references/layout.md#原生箭头与标注图形)。默认不遍历内置样例或模板库；有用户参考时提取视觉结构，以现有原生节点表达，具体构图随内容变化。两份文件足以规划，不增加独立模板生产阶段或旧 brief/plan/theme 校验链。
3. 完整新课件默认采用原生讲解页＋HTML 互动页混排。逐页优先判断是否能让学生选择、排序、匹配、拖动、预测验证或调整参数并获得反馈；适合的页优先用 HTML，活动分布在导入、探究、练习和归纳中，不以全篇或每课时只有一个活动为目标。纯阅读与教师完整示范等更适合原生的页简记理由；用户明确纯静态、少量指定页或局部编辑时按用户范围执行。按 [互动课件页](references/interactive.md) 记录并实现任务、操作、反馈、结论与重置，沿用 DESIGN 的配色与图像语言。原生淡入和点击揭示用于讲解节奏，不能替代已规划的 HTML 活动；复用本课公共样式与操作逻辑提速，不通过减少适合的互动页提速。
4. 创建或打开 EN 课件并呈现。按 [可组合布局](references/layout.md) 批量制作，建议每批 3–4 页，在同一次 codemode 中顺序调用 `tools.courseware_edit`；每次新增布局页的工具调用仍只提交一个 `insertSlideLayout`。STORY 中已规划的元素动画或页面过渡随该页提交 `page.animationPlan`，批次循环保留完整 page 对象，明确静态的页才省略；按 [教学动画](references/animations.md#失败撤销与交付) 分别确认内容与动画结果。HTML 互动页用独占 insertHtmlPage 按页序插入，随调用验证主路径与重置，再发布初始截图和入口；这项写入前验证不要求模型逐步截图。内容较大、接口限制或剩余页数不足时缩小批次，不为凑数增加页面。排版前算清固定尺寸、间距和内边距，为 1280×720 画布留出余量；使用 `flex` 分配剩余空间。首批普通正文写入后按[正文风格校准](references/review.md#正文风格校准)前移一张真实截图，对照适用个人规范检查栏目、角色样式、图题答案关系及颜色语义，先纠正会扩散的样式缺口；其余创建阶段记录真实 ID 和待查问题，不逐页截图返工；写入前校验失败只修正阻止创建的输入，未知写入先核对实际状态，不能重放已完成页。专业图先按 [学科专业技能接入](references/subject-integration.md) 执行对应生成与验收，物理静态图必须完成 [物理图接入](references/physics-integration.md) 的专业产物链路后插入；非专业技能覆盖的纯数学函数、几何与坐标图按 [理科绘图](references/math-visuals.md) 声明 diagram，由工具绘图和登记，不以形状线段硬画。普通配图按批复用或搜图；首轮和针对性补搜都缺少合适素材时，直接为适合 AI 示意的教学主图执行[生图兜底](references/design.md#素材准备与复用)。教学配图实际看图确认后，用登记的 assetId 插入 STORY 对应页；封面也可使用搜到的照片或生成的插画。按主图的主体位置安排原生标题；正文先排教学图、文字、图注和作答区。有共享角饰时，只在符合该页构图的页面启用。组合文本与容器时避免无意义的满高空卡片，不预写全篇页面源码。按 [局部修复](references/layout.md#失败后的局部修复) 保存当前批次草稿与写入进度；失败只修当前页的错误节点，保留原定背景装饰、配图、动画和 HTML 互动及验证，不以删除设计来通过校验，不重复输出或重放整批。
5. 全部目标页面创建完成后，进入 [检查与交付](references/review.md)：复用写入回读核对全篇内容、个人规则对应表及已规划的呈现节奏是否落实，全程默认抽查 2–3 张高风险或代表页截图（含前置正文校准），小课件可更少。仅对具体问题页补充截图，不为凑全页 passed 逐页抓图。修复采用现有元素的局部修改，交付区分内容核对、动画配置与实际视觉抽查范围。
6. 后续修改以当前 EN 文档为准，按 [编辑](references/editing.md) 处理，不用旧布局源覆盖用户手工修改。互动页在同一会话局部修改 HTML，以 updateHtmlPage 原位更新，不追加替代页；具体身份、版本与失败处理见互动参考。

制作时按 [视觉层级与密度](references/visual-rules.md) 保证任务完整、主次清楚与全篇一致；不以最低字数或填充率要求补文案。排版只因真实文字放不下、明显画布裁切、字号或输入错误阻断；容器/边距提示留到集中抽查，不触发逐页修复。按局部修复与检查参考的有限轮次处理失败，优先交付完整可用课件。

需要落盘的课件规划、风格预览、批次草稿及降级后的本地教学设计放在 Session 工作区 `en-courseware/<课题短名>/`；已创建的云教案不额外落盘，用户明确要求本地副本或导出时除外。用 TSX 生成新版布局树作为工具参数；调用历史保留输入，无需额外抄写每页 JSON。图片使用已登记 assetId。用户提供视频时按[原生视频](references/video.md)直接在 `courseware_edit` 的 addVideo 或原生 video 节点提供文件/直链，由编辑操作内部准备资源；规划播放区间，不自行搜视频或用封面冒充视频。权限、审批、身份和 EN 原生写入回执仍由现有工具执行；未知写入先核对，不能直接重试。

用户要求把已引用或已选中的在线网页插入课件时，优先用 `courseware_edit` 的 `insertOnlinePage`。云盘互动网页和仿真实验传业务 ID 及可选版本，公开网页只接受 `*.seewo.com` 子域名下的稳定 HTTPS 最终播放地址，裸域和外站链接不适用。明确要求「搜索并插入」且有一个明确匹配的合规结果时，沿用写入审批直接插入并告知选用来源。作为新第 N 页插入时，锚定原第 N−1 页之后，第 1 页用 `start`，未指定位置时追加。此流程直接复用在线网页，无需读取或改写 HTML。回读新增页及同步状态，实际播放需要独立验证。

文件操作使用工具返回的真实工作区/文件路径或已确认的 Session 相对路径；参考文件按当前 Skill 所在目录解析。不凭记忆重拼用户标识、长目录名或猜测安装位置。遇到 ENOENT 先核对路径，不改写为另一条猜测路径连续重试。

让课题参与排版：比较项对齐，推导按变形顺序排列，朗读的停顿与重音通过分行和疏密体现。先给教学主体足够空间。用现有留白安放可辨识的主题图案，或用低对比背景衬托内容。若图案抢焦点，先调整范围、位置或对比，为阅读和作答留出净区。每次新课件按课题、学段与用户偏好变化配色、素材和构图，具体见 [通用配色与风格变化](references/themes.md#通用配色与风格变化)；同一套内统一，续编或用户指定风格时沿用，不重复抽选。按 [通用配色背景与教学配图](references/design.md#通用配色背景与教学配图) 落实情境图和解释图；纯数学的精确关系用 diagram；专业学科图按专业接入规则生成，不因包含曲线或坐标而绕过专业技能。简单面积拼补可用按数值关系构造的原生形状，装饰不能替代教学主图。HTML 活动继续按上述混排要求制作，不因视觉优化省略。
