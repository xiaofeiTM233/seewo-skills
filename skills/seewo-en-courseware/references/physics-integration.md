# 物理教学图：接入与验收

## 边界与启用

在课件中制作或修改承担物理教学含义的图时使用。新课件先完成主技能的教材核对、个人风格和资源准备。

电路、受力、光路、场、实验结构、热学与波形、物理数据图等在 STORY 规划时识别，按 [学科接入](subject-integration.md) 委派给当前可用 seewo-physics-illustration。新生成或实质改动的静态专业图必须执行该技能实际工作流，不仅借用其规范。绘制前读取当前版本 SKILL.md、新图必读的 references/style.md 及相应图类参考；宏和脚本按实际需要读取。路径只取当前技能目录，不猜安装位置，也不把用户私有的能力说明路径写入技能。它不是可直接调用的工具；编译、资源登记及编辑均核对真实工具声明。

物理插图技能不可用时，本页的最低科学性要求仍生效，但不得将其他方式绘制的图称为该技能产物；按下文受阻流程处理。当前版本只支持静态输出时不假定存在跨载体引擎。发现参考与题目、可靠学科结论冲突时不照抄，核对并更正；关键条件不明用 ask_user 补齐。

## 绘图分流

| 内容职责 | 方法与边界 |
| --- | --- |
| 电路、受力、光路、场、实验结构、热学与波形等覆盖范围内的静态示意 | 必须执行 seewo-physics-illustration 的 TikZ/circuitikz 生成与导出流程，实际审阅后插入；不以普通 diagram、手拼图元或生图绕过 |
| 物理函数与数据图 | 同样走专业技能静态生成流程，核对物理量、量纲、单位、定义域、数据来源；实测点不伪装成解析曲线 |
| 纯数学函数、几何、坐标图 | 不承担专门物理语义且非本技能覆盖的纯数学图，继续按 math-visuals.md 使用 diagram；不能仅因有坐标轴就将物理图归为纯数学 |
| 分步揭示 | 专业技能生成对齐的底图、分层或状态图，课件主流程组织揭示；不把包含答案的整图冒充可揭示图层 |
| 连续调参或拖动模型 | 读取专业规范核对模型；可用静态底图仍由专业技能生成，动态部分由课件 HTML 的 SVG/Canvas 按同一模型重算，分开记录来源。不声称 seewo-physics-illustration 产出动态仿真 |
| 实物和仪表读数 | 核实过的真实素材；示意图不充当实测记录或真实仪器照片 |
| 情境与装饰 | 可搜图或按授权生图；与证据图区分，不暗示其结构或读数可用于推理 |

普通装饰不进入物理图内部；课程整体可保持个人风格。物理图的线型、箭头、量与单位语义不能被皮肤覆盖。教材约定与科学性优先，个人颜色语义在不制造误解的范围内承接；线型和文字同时承担辨识，不能只靠颜色。

## 专业静态图的执行闭环

1. 从 STORY 取得题意、条件、状态与目标图区，先审定物理模型再绘图。不复制能力说明中的示例充当本题正确图；不为了网格或排版改变物理关系。
2. 按物理插图技能选择当前会话的渲染路径。有内置 `visual_render` 时通过该工具提交完整 TeX 源码。本地路径按实际所需核对 XeLaTeX、宏包、字体及导出工具，使用 Node 前遵循 workspace-runtime。
3. 按当前技能的 scaffold 说明在本任务过程目录生成内联宏的单文件源码。先搭支承、光轴或回路骨架，再放对象、矢量和标注。分层图固定同一坐标与画布，避免揭示时跳动。
4. 执行渲染并检查实际产物。内置路径检查 PNG 及登记回执，本地路径按目的选择 EN 支持的图像格式。编译失败定位首个实际错误并局部修复同一源稿。
5. 实际打开渲染图并按专业规范检查，图片须进入模型视野；必要时批量查看，每幅独立新图均覆盖。确认模型、方向、虚实、箭头、单位、比例、标注和出界；编译成功不代表科学性或画面通过。修图后检查变更版本，不沿用失效证据。
6. 用当前真实素材能力登记合格产物，在目标页使用返回 assetId；通过写入回执或定向回读确认实际引用，并建立 figureKey、源稿、产物、assetId 与真实 slideId/elementId 的关联。图内结构或数值变化时改同一模型源稿、重新生成并局部替换相应图，不覆盖用户其他页面修改。
7. 在已有代表页抽查中检查实际缩放、遮挡、标签可读性和答案揭示；原生动画配置、真实播放与保存/重开分别记录。不逐图增加整页截图门槛。

只读手册、只产出源码、只登记图片、只输出路径或编译命令，均不是完成上述链路。同课内相同图可复用已生成产物与有效检查证据；变式只重做变化部分，但物理关系仍需核对。

## STORY 内的物理图记录

在现有页面行或紧邻短表中记录，不新建重复计划：图标识、教学任务、研究对象与假设、已知量与单位、定量/定性、关键关系、初始/变化/揭示状态、渲染方式、检查点与素材来源。图标识是本次内部对应名，不伪造 assetId。补充目标 pageKey、专业技能、预期分层/状态及目标图区；生成后在同一记录关联真实产物与页面，区分计划、已生成、已检查和已插入。

定量图的箭头比例、坐标及曲线来自数据或公式；定性图明确不供量取，不把未知量画成可推断大小的比例。支点、接点、作用点、光线交点和曲线端点按关系计算，不为对齐网格改变物理意义。涉及教学结论的假设就近说明。

至少核对：
- 电路：先定义元件端子与节点再布线；交叉相连/不相连须明确；电表接法、量程和极性与题目一致；变阻器先确认接线柱和有效电阻段。短路状态不套用理想 I=U/0 生成无穷读数。
- 力学：先定研究对象与相互作用。质点化受力图可共点；刚体、杠杆和力矩图保留作用线/作用点，不能强制共点。重力始终竖直向下；向心力是径向合力，不额外添加为一种作用力；力臂是支点到作用线的垂距。摩擦力依据接触面相对运动或趋势。
- 光学：真实光线与虚延长线分开；法线、焦点、像的位置由对应模型决定。薄透镜需声明近轴理想化；物距等于焦距时无有限像，不能除零；接近焦点出视口不等于像不存在。
- 实验与图像：器材结构、变量、单位、刻度、测量范围、有效数字与材料对应；合成示例数据明确标注，不冒充实测。

## 旧版参考的防误用

不能把“曾编译通过”当作物理审定。遇到旧版“一切力都共点”“端点箭头只表示力”“所有图都可按比例量取”时，按上述模型分类纠正。

旧版力学示例尤其先审定：悬挂结点平衡的水平力方向与三力合成；平抛轨迹顶点及速度方向；竖直圆周最低点重力；单摆与小角度近似的区别；浮力图的受力状态、浮心和排液体积标注。旧图或代码不能直接作为金标准；条件不成立的示例停止复用，按本题关系重新制作。此提示不是声明全手册已完成审校。

## 制作与载体适配

稳定底图与问题、答案、推导分开；图内标签绑定对象，课件标题与推理尽量保留为原生文字。需要分步揭示时先明确基础层、矢量层、辅助线层和答案层；不能使用一张含答案的底图冒充分步揭示。

整页可以是 16:9，嵌入图按图形内容和版面区域定尺寸，保留安全留白；等比缩放，不强行拉伸成 16:9。检查实际嵌入后的标签、线条和箭头。静态图导入 EN 后通常是整体图片，不承诺图内元件原生可编辑；diagram 的源恢复按其真实合同处理。

动态页用同一模型状态派生参数、图形、读数及结论，注明范围和理想化条件。连续变化用重新计算，不仅平移图片或替换文案。测试至少覆盖初态、典型变化、适用边界和重置；超出模型范围显示明确状态而非捏造读数。复用互动页 verification，但它只验证可观察行为；科学性另按本页核对。

## 受阻与替代

专业技能、运行时或编译/导出能力缺失时，先保留模型、已有源码、实际文件和未完成项，说明哪些图尚不能插入，继续不依赖它的已授权页面。历史环境说明不能代替当前检查。失败、权限拒绝与结果未知分开处理：未知先核对产物或业务状态，拒绝不得换接口重试。

不得自动安装依赖、推荐安装、调用虚构绘图服务，或以 AI 生图、错误简图、占位框冒充完成。由于静态图已明确要求专业技能生成，改用 diagram、手写 SVG 等路径必须先用 ask_user 取得对这一替代的明确选择，不能仅告知后静默替换；仅使用已可用且能准确表达图意的确定性方式。用户确认替代后保留例外原因、实际实现来源与未完成的专业生成要求，不报 seewo-physics-illustration 生成成功。是否改变编辑性、交互或交付形式也必须说明。连续动态的正常分流不属于此类失败替代。

只有源码时不能插入 EN，也不能宣称已完成专业配图；已生成且检验合格的支持格式可用于接入，但未取得的其他格式及未检查项仍明确保留。素材登记失败则保留图，不能自造 assetId；页面写入结果未知时回读目标页，不能重复插页。

素材通过现有真实资产工具登记后再插入；不得自造 assetId、持久地址或假定 SVG 必然可直接导入。查验回执中实际格式、资源和目标页。源稿、图及检查记录在本任务已有过程目录保存，不逐图增加最终成果卡；单独索要插图时按其交付规则。

## 分层验收

1. 先按 STORY 核对每幅静态专业图确实由指定技能生成、取得可用产物、通过真实素材登记并用于正确页面；允许的例外有用户确认及实际来源。再核对对象、条件、公式、拓扑、方向、比例/示意、标签与结论。相同模型的变式检查变化及保持量。
2. 新生成或实质改动的专业图逐图查看渲染结果，可按批展示；复用相同内容的有效图证据，不重复截图。图片必须实际进入模型视野才能记为看过。
3. EN 全篇仍默认抽查 2–3 张高风险/代表页，兼顾物理图嵌入后的可读性；素材检查不等于全页视觉检查。具体裁切、遮挡或新模型风险才补查。
4. 动态图另测典型状态、边界和重置，核对图形与反馈一致；隔离测试、真实播放、保存及重开分别记状态。

状态分为：已检查且有证据、未检查、受阻、不适用。代码存在、编译成功、工具测试通过均不能代替物理审定。物理错误为阻断项，未修正不得作为正确示例交付；可交付其余已完成部分并明确缺口。不声称学习效果已验证。
