# 学科专业技能接入

完成所需的教学准备后，在 STORY 按页查表。专业技能负责学科模型、素材与专业核对，EN 主流程负责选载体、适配本课与插入验收。执行前读取当前会话的技能正文，核对生成方式和 EN 接入能力。普通配图沿用常规素材流程。

| 学科任务 | 专业技能与产物 | EN 接入 |
| --- | --- | --- |
| 展示电路、受力、光路、实验结构或物理数据图 | `seewo-physics-illustration` 生成图，见 [物理图接入](physics-integration.md) | [静态图](#静态图) |
| 展示化学结构式或方程式 | `seewo-chemistry-structure-equation` 生成静态 SVG | [静态图](#静态图) |
| 分步展示受力箭头、辅助线或答案 | 专业技能生成所需底图与状态图，EN 可补原生标注 | [分步揭示](#分步揭示) |
| 拖动模型或连续改变物理参数 | 按专业模型在本课 HTML 中重算 | [互动 HTML](#互动-html) |
| 旋转分子或练习配平 | `seewo-chemistry-structure-equation` 生成单文件 HTML | [化学互动页](#化学互动页) |

## 静态图

1. 执行表中对应的静态生成流程并查看实际图片。化学图核对结构、反应条件、上下标、电荷与箭头。图内方向、线型、单位和比例按学科语义保留。
2. 优先复用合格的 PNG、JPEG、WebP 或 GIF。只有 SVG 时，用 `describeTool("images_convertSvgToPng")` 确认可用，再调用 `tools.images_convertSvgToPng({ path })` 生成并查看 PNG。工具缺失时，先确认会话 Shell 是否有 `easinote-svg-to-png <源.svg> <输出.png>`，或使用专业技能已有的 PNG 导出。
3. 用转换回执的 `coursewareSource` 插入。已有本地图片可在 `images_register` 可用时预先登记供复用，或按当前 EN 工具声明直接传 `{ kind: "file", path }`。核对目标页的写入回执，随全篇代表页抽查图中文字、比例和遮挡。

## 分步揭示

把题干和底图放在首屏，把受力箭头、辅助线或答案等后续内容做成独立图层或原生元素。用专业技能生成所需底图和状态图，各层共用坐标和尺寸。按 [教学动画](animations.md#生成) 提交本页的 `animationPlan`，核对目标元素、揭示顺序和首屏是否提前露出答案。

## 互动 HTML

按 [互动课件页](interactive.md) 规划核心操作、反馈与重置。物理连续调参按 [物理图接入](physics-integration.md#绘图分流) 确定模型，底图可复用专业技能产物，动态状态由 HTML 按同一模型重算。

### 化学互动页

1. 按化学技能正文，用 `chemistry.py` 的 `render-molecule` 或 `render-equation` 加 `--mode interactive` 生成所选案例的单文件 HTML。同时需要静态图时用 `--mode both`。三维活动选择有模型数据的案例，配平活动先核对反应物、生成物和条件。
2. 将 HTML 按本课风格适配为 1280×720，保留内嵌素材、模型和脚本，保存到 `en-courseware/<课题>/interactive/<pageKey>.html`。给参与验收的控件和反馈节点补唯一的 `data-cw-id`，落实可点击的重置。配平可用加减按钮覆盖系数调整，三维页补齐视角复位。
3. 按 [互动验证规则](interactive.md#一条有界验证流程) 为核心操作提供 `initial`、`steps` 和 `resetTarget`。配平核对系数变化、元素与电荷守恒及最简整数比反馈，三维可用视图状态文字验证切换。通过 `tools.courseware_edit` 的 `insertHtmlPage` 提交相对路径、`pageType: "interactive-html"` 和 `verification`。
4. 核对目标页和验证回执。在代表页打开互动弹层，检查实际操作与重置，三维页确认模型可见并能旋转。分别记录隔离验证和真实播放，未上屏的页将播放记为待验证。

## 记录与受阻

在现有 STORY 页记录 `pageKey`、图的 `figureKey`、用途、所用技能及影响结论的条件或假设。静态图记实际文件或回执 `assetId` 及插入结果，分层图补各层和揭示顺序，HTML 记源稿、`slideId` 和验证结果。相同素材可复用，条件改变时重做并核对受影响部分。

当前会话缺少转换入口、专业技能或执行依赖时，保留已有源稿和待补页，继续可独立完成的内容。生成或适配失败时局部修正。权限拒绝时停止该项，写入结果未知时先回读目标页。影响结论的条件有缺失，或需要改变指定生成方式、成果形式时，用 `ask_user` 合并确认。专业图按实际来源记录，精确关系使用有结构或计算依据的产物。

新增学科映射前，核对技能当前版本的覆盖范围、执行依赖和真实产物。生物图示暂未配置专用接入规则。
