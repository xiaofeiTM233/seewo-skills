# 运行时主题基线

主题提供颜色 token、字体角色及字号下限，不负责选择构图，也不与学科绑定。由模型结合课题、学生与用户偏好自主决定视觉方向；同一主题可以采用完全不同的构图与素材，不读取内置视觉样例。

| theme    | 默认色彩倾向               | 默认字体角色         |
| -------- | -------------------------- | -------------------- |
| academic | 浅底、蓝色强调             | 无衬线               |
| navy     | 浅底、海军蓝强调、金色点缀 | 无衬线               |
| red-gold | 暖底、深红强调、金色点缀   | 衬线标题、无衬线正文 |
| ink      | 米白底、墨色文字、朱砂强调 | 衬线标题、无衬线正文 |
| bright   | 暖白底、青绿色强调         | 无衬线；正文下限较高 |

这些是当前接口接受的 theme 值，不凭空添加新的名称。具体色值由运行时维护，颜色用途与可用节点样式见 [布局](layout.md#主题与自动调整)。允许通过已支持的颜色、字体、背景和素材属性定制；主题选择不要求固定标题位置、角饰、卡片或图文比例。

全篇保持文字层级、颜色语义和素材媒介一致；装饰随具体课题设计，不依照“某学科必须某种纹样”的规则。字体按环境实际可用情况回退，不能假定设备具有某个字体。页面自适应仍遵守主题字号下限，不为风格降低可读性。

## 通用配色与风格变化

先从已读取的个人规范确定稳定的颜色语义、角色样式和背景约束。下文新课件变化与候选探索只用于未限定部分；已确认方向不进行随机替换、不因近期用过便主动避开。新作品仍可继承同一教学语法。无适用个人方向时才完整采用以下默认探索策略。

全篇保持清楚的配色层级。背景可用净色，主题可以由主图和文字构图体现。选一个现有 theme 作为字体与默认色基线，再在 DESIGN 和共享常量中确定本课的主色、辅助色、点睛色、深浅背景及可读前景。学科名不决定色板，运行时 theme 也不等于最终视觉风格；同一 theme 可有不同的配色、素材媒介和构图。

可从以下搭配发散，也可自主创作；这些是灵感示例，不是按顺序轮用的预设，不固定选第一项：

| 色彩方向         | 可探索的素材与背景语言                 |
| ---------------- | -------------------------------------- |
| 湖蓝＋珊瑚＋米白 | 透明水色、切面色块、局部场景插画       |
| 松绿＋杏黄＋暖纸 | 植物线稿、纸感纹理、自然摄影与边饰     |
| 靛紫＋蜜橙＋淡青 | 几何拼接、轨迹线、深浅分区与图解       |
| 陶土＋青绿＋砂白 | 剪纸拼贴、肌理色块、图鉴或手绘标记     |
| 莓果＋青柠＋奶油 | 轻快插画、曲线边框、明亮主题图案       |
| 墨蓝＋金赭＋雾灰 | 深浅背景交替、细线纹样、摄影与局部留白 |

每次新建课件，从当前课题的意象、任务与受众提炼视觉方向，再组合色彩、背景材质、图片媒介、标题语言和构图。不同方向应在多项视觉特征上有明显变化，不能只替换标题或微调同一蓝色。配色和样式的探索在现有 DESIGN 阶段一次完成，不额外生成整套候选页面。

用户未指定风格时，避免总取默认主题或候选首项；同样适合的方向可一次轻量随机选择，再按内容定制。当前对话或用户提供的参考中已有近期作品时，主动避开其整套配色与构图组合；没有可比较历史时不声称已做跨会话去重，也不为选风格扫描其他会话或建立历史库。用户明确沿用风格、品牌或续编同一套课件时优先保持一致。

方向确定后在本套内稳定颜色含义、字体角色与装饰动机，让页面随教学任务变化；原生页与 HTML 活动承接同一设计。将最终选择保存于本课 DESIGN，恢复与重试复用它，不重新抽选。

定制色在 [createCoursewareDesign](components.md#课件级风格与语义富文本) 的 spec.palette 中维护一份，apply 将公共组件、手写节点和富文本的 token 展开为具体颜色，并导出同源 CSS 变量。palette 是创作辅助函数的参数，不能直接加到 page 或 PageFrame；page.theme 仍是上述五个值，字号下限不变。需要深浅变体时从同一 spec 派生前景、背景、强调色配对，避免只换深底留下深字；图片与 diagram 使用实际选定素材和颜色，不会被自动重新着色。装饰背景遵循 [背景与装饰规则](design.md#通用配色背景与教学配图)。颜色结合文字、形状或线型表达意义，不作为人物、类别、正误和变量的唯一线索。
