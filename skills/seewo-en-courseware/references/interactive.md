# 互动课件页

完整新课件默认混排原生讲解页与 HTML 互动页，STORY 对每页做互动适用性判断，适合学生操作并获得反馈的页优先用 HTML。用户明确纯静态、仅少量指定页或局部编辑时遵守其范围。参数探索、拖拽建模、分类、预测验证或练习反馈使用自包含 HTML/CSS/JavaScript；简单分步揭示继续使用原生动画，但不能用动画页或只有“显示答案”按钮的静态讲义替代已规划的 HTML 活动。模型自由设计，不预读整页示例或从固定互动模板中选型。

## 逐页选择与互动分布

先判断学生能否通过实际选择、操作或试验影响页面并得到有教学意义的反馈。能做到时优先互动；不能时保留完整阅读、观察或教师示范，并在 STORY 简记理由。不要将“适合 HTML”限于复杂模拟实验，也不要按每课时只做一个综合互动页：短小的证据判断、步骤排序、图文匹配和方法选择同样能让日常教学页可操作。

| 学习任务   | 可操作的表达                                                       |
| ---------- | ------------------------------------------------------------------ |
| 观察与预测 | 先选择预测，再改变条件或观察对象，反馈预测与证据是否一致           |
| 阅读与理解 | 选择证据词句、匹配图文或人物观点，给出依据；开放题保留多种合理解释 |
| 推理与建模 | 排序步骤、拼补图形、选择下一步或调参数，反馈关系与理由             |
| 练习与辨析 | 分类、选择方法、定位错步并改正，给出针对性反馈和再尝试机会         |
| 归纳与迁移 | 补全关系图、匹配概念与情境，用结果回收本课结论                     |

这些是交互任务建议，不是固定模板。将活动分布到对应学习环节；多个步骤属于同一连续任务时可在一页推进，不为提高占比拆碎页面，也不把无关活动塞进一个“大综合页”。规划结束查看 HTML 页码与占比，发现连续可操作的任务仍只有静态展示时优先调整，不把“已有一个互动页”视为完成标准。

复用本课已完成活动的公共 CSS、Pointer Events、反馈和重置逻辑，按各页任务替换内容；共享代码在制作时内联进各自源稿，每页仍自包含并分别验证。优先实现一条清楚、可复位的核心操作，避免不必要的复杂游戏流程拖慢全篇生成。

## 教学与画面

在 STORY.md 的该页记录：学生任务、核心操作、预期反馈与教学结论；在 DESIGN.md 既定视觉规格下安排页面，沿用原生页的标题标记、配色和提示样式。用本课 [createCoursewareDesign](components.md#课件级风格与语义富文本) 导出的 cssVariables 构造页面 CSS 变量并实际使用，不另抄一套硬编码颜色；主题素材和概念/证据的强调含义一并复用，HTML 的状态变化仍单独实现。支持教师或学生在同一块大屏上操作，不设计多设备答题服务。为操作与反馈保留空间，不用大段说明挤占操作区。

活动放在对应的探究或练习环节，初始画面就有可辨认的模型或任务对象。例如配方法让学生拼补面积并判断缺口，判别式探索让参数、图像和根的情况联动；状态改变有准确反馈，并可重置。模型假设和适用范围按题目明确，不用仅换文案的按钮冒充操作反馈。各学科的活动图片、人物或模型与原生页保持一致的配色、标签和主题背景，交互重点可有更鲜明的局部色彩；背景避开操作控件与反馈区。

已规划的活动须实际插入 EN；只写出 HTML 文件不算完成。生成或插入失败遵循现有恢复与验证规则，无法完成时明确保留该活动缺口，不静默改为静态页或宣称整套完成。

源稿保存到当前 Session 工作区 `en-courseware/<课题>/interactive/<pageKey>.html`，pageKey 使用字母、数字、下划线、连字符。每页独立，按需修改当前文件；源稿只保证在当前会话可继续编辑，不承诺跨会话/设备恢复。已有持久 URL 可以播放，但不是可恢复的本地源稿。

传给 insertHtmlPage/updateHtmlPage 的 `path` 必须是上述工作区相对路径，不能拼接工作区绝对路径。中文课题名受支持；遇到 PATH_INVALID 先检查相对路径、interactive 目录和 pageKey，不因报错重命名整个中文课题目录或重建课件。

固定 1280×720，html/body 清除默认 margin，采用 border-box；加载后立即呈现初始画面。内联 CSS/JS/SVG/Canvas；图片使用登记 assetId 或带 `#asset:img_实际ID` 的真实相对资源路径，由工具校验并嵌入。不可使用远程脚本/CDN、在线字体、外部 API、上传、业务凭据或父窗口桥。鼠标与触控共用 Pointer Events，不能只支持悬停或键盘。必须有明确操作提示、可见反馈及“重置”；动画可暂停和复位，每次重新打开从初始状态开始。

导入后是整页初始截图背景与原生 AITool 打开按钮。网页中的文字不成为 EN 原生可编辑文字。编辑预览和演示均在课件内弹层运行，关闭回到原页；首次加载需网络，加载后操作自包含。入口、编辑预览和演示关闭控件使用 AITool 默认样式，不在课件内重画宿主按钮。加载提示沿用 SDK，不能宣称已提供统一超时重试；网络恢复后可关闭重开。源稿不自建宿主加载桥。

## 物理互动的额外要求

按 [物理图接入](physics-integration.md) 先确定模型、参数范围和边界。同一状态派生图形、读数、单位与反馈；连续变化重新计算，不只移动底图或切换结论文案。至少覆盖初态、典型变化、边界及重置；临界无有限解、超视口与非法输入分别处理。静态底图适用于辨析和揭示，不冒充连续仿真。下面的行为断言不能替代物理关系核对，真实播放与图像审查另记证据。

## 一条有界验证流程

每页提供 `verification`，随插入/更新由 Host 在同次隔离渲染中执行真实输入。控件和反馈节点使用唯一、可见的 `data-cw-id`（字母开头，后续字母/数字/下划线/连字符，最多64字符）。只提供下列声明，不提供任意检查脚本：

- `initial`：1–8 条初始状态断言；选择能证明重置的答案、参数、反馈或位置。
- `steps`：1–6 步，每步有 `action` 与1–8条 `expect`。
- `action`：`{kind:"click",target}`、`{kind:"drag",target,to}` 或 `{kind:"range",target,value}`。range 对应标准水平 input[type=range]，保留默认滑块几何，不自定义 thumb 尺寸。
- 断言：`{kind:"text",target,equals:"可见文本"}`（去首尾空白后的精确匹配）、`{kind:"value",target,equals:"字符串"}`、`{kind:"checked",target,equals:true}` 或 `{kind:"inside",target,container}`（实际边界在容器内）。每个字符串最多512字符。断言的预期字段始终是 equals；range 动作的输入才用 value 数值，例如 `{action:{kind:"range",target:"delta",value:1},expect:[{kind:"value",target:"delta",equals:"1"}]}`。
- `resetTarget`：可点击的重置控件 ID；执行后 Host 重新断言 initial。

每条主路径都应引起可观察的反馈或参数变化；不要仅断言一个始终存在的标题。Canvas/SVG 的变化需配套可观察数值或结论，断言通过不证明数学与教学结论正确，内容仍需核对。验证清单可与源稿同目录保存，不另建全篇流水线。

拖拽时用目标容器 getBoundingClientRect 与 pointer 坐标判断落点；拖动物体覆盖指针时，elementFromPoint 可能命中卡片自身。若使用命中测试，须在测试时排除拖动物体。共用 Pointer Events，并覆盖拖拽归位和重置，避免首次验证才发现计数未变化。

## 插入与原页修改

继续使用 `tools.courseware_edit`，每次只有一个 HTML 操作。通过 describeTool 核对实时合同：

- 插入：`{kind:"insertHtmlPage",path,pageType:"interactive-html",anchor,verification,note?}`。anchor 为 `{kind:"start"}` / `{kind:"end"}` / `{kind:"after",slideId}`，省略为末尾。与原生布局页按 STORY 页序顺序写入。
- 更新：`{kind:"updateHtmlPage",path,pageType:"interactive-html",slideId,verification}`。保持原路径，外层必须带新 `operationId` 及最新 `expected:{editorInstanceId,revision}`；从真实 manifest 获取版本，不沿用上一轮估计值。一次新修改一个操作 ID，同次重试保持同一 ID 和参数。

成功后记录 `html.path / slideId / sourceDigest / verification` 与原生回执。Host 在当前 Session 绑定源路径与原生页、预览背景和卡片；更新只替换该页受管资源，保留页序、元素身份、教师追加内容及当前几何位置，支持撤销；不重新建页，不覆盖教师备注。源稿不存在、映射缺失或目标已改动时停止该页更新，说明缺口。

## 失败与交付

验证失败只修该页相应节点或逻辑；最多两轮定向修复仍失败时报告并停止该页写入。`HTML_COURSEWARE_NEEDS_REPAIR` 包含阶段、目标及预期/实际值；`HTML_VERIFICATION_REQUIRED/INCOMPLETE` 不能省略验证后绕过；发布失败不使用临时 URL。

`HTML_PAGE_ALREADY_INSERTED` 改走原页更新；`HTML_UPDATE_VERSION_REQUIRED` 补齐真实版本；`HTML_PAGE_SOURCE_UNAVAILABLE` 不从截图猜测原稿；`HTML_UPDATE_TARGET_CHANGED` 或版本冲突先读取当前页。`HTML_PAGE_OUTCOME_UNKNOWN` / 超时 / 断连先查 operation-status 与实际页，不改路径或操作 ID 重放。生成、验证、发布均不等于 EN 写入完成。

回执 `html.verification.status=passed` 只证明隔离渲染中的主路径与重置；`playbackVerification=notVerified` 表示真实托管 URL 的桌面打开未验收。全篇默认抽查2–3张代表/高风险截图，互动每步无需截图；实际编辑预览/演示打开、同步与重开单独报告。不要把隔离验证、截图或写入回执当作这些状态的证明。
