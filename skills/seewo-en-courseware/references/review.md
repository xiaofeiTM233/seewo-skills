# 检查与交付

默认采用一次前置正文风格校准＋全部目标页完成后的集中检查；全篇内容核对与少量视觉抽查相结合，不逐页截图，不以 review/status 全页 passed 作为交付门槛。用户明确要求逐页视觉验收时才扩大到全篇。

## 个人规则核对

交付前按 STORY 的个人规则对应表逐条检查，状态区分「已落实且有对应证据」「已配置但未验证」「未落实」「不适用」「合理例外」，说明例外依据；不把不适用算通过。教学组织通过全篇页序、内容及回读核对，视觉呈现通过现有代表页截图检查；揭示节奏区分配置、真实播放与重开证据。读取成功、写入成功和视觉抽查分别报告。发现遗漏不得删除原规划规则以制造合规；修复或保留真实缺口。没有规则来源或文件未完整读取时不声称完整复现。

不新增全页截图门槛：在原有 2–3 张代表页范围内优先兼顾个人页型、答案落点或同图变式；规则需要的视觉关系尚未覆盖时如实保留未验证范围，仅具体风险或用户明确要求才补查。没有教师真实校准，不报告「更像我已获认可」；没有学习证据不推断教学效果。

## 专业技能产物接入核对

按 [学科专业技能接入](subject-integration.md) 对照 STORY，核对应委派的图是否执行了真实专业工作流、取得产物、完成图级检查和素材登记，并在正确 slideId 使用对应 assetId。只读规范、源码、日志、路径或未用素材不能算完成；替代方式须有相应确认，写明实际来源，不冒称专业技能生成。专业内容、图像审阅和 EN 页面抽查分别计证据；按当前会话实际使用的学科技能记录产物。

## 物理图的科学性核对

按 [物理图接入](physics-integration.md) 核对每幅独立图的研究对象、条件、公式、拓扑、方向、示意/比例、标签及结论；新图或实质修改的图须实际审阅渲染，可按批看图并复用有效素材证据。这是图级检查，不将 EN 页面抽查扩大为逐页截图。原有 2–3 张样本优先兼顾嵌入后的可读性，具体风险才补查。动态物理图还要核对典型状态、临界状态及重置后的图形—读数—反馈一致。科学性错误阻断相应内容交付；编译、行为断言、图片登记或页面写入成功均不等于物理正确，未测部分如实保留。

## 正文风格校准

新课件首批有代表性的普通正文页写入后，取一张真实 EN 截图；从默认 2–3 张代表页中前移这一张，不增加四套候选原生渲染或每批抽查。有风格选项时优先抽查与所选样卡内容或页型对应的正文页；已有同一套课件的有效校准或本次仅局部编辑时复用，不重复启动。

收到图片后按既有证据流程提交观察，再检查：第一焦点的实际尺度是否足够；重点短语是否进入富文本；选定方向的配色、字体与背景特征是否在正文可辨认；个人规范中适用于本页的栏目名称与位置、角色层级、图题答案关系、语义颜色是否落实。个人规则遗漏与通用风格缺口同样须纠正，不能只检查是否美观。缺失主图、样式退回基础主题、承诺的材质完全未实现属于交付缺口，不能统称审美偏好。优先修共享 spec/结构和当前页，再继续后续批次；已写入页只做局部修改，不重放插页。不为几像素间距或装饰偏好循环校准。

先按 STORY 核对教学素材，再把所选方向、DESIGN 的计划和代表页截图对照，确认背景图稿的轮廓、覆盖范围及辨识度与样卡对应，并让位于教学内容。若选定的航线、纸纹或主题轮廓在成稿计划里被改成普通纯色和标题标记，先恢复相应图稿或分区，再用已有抽查验证。同时用本批已保存的实际页面参数核对净底例外。计划与写入不一致时先确定该页应使用的版本，再修正页面或记录。背景素材的登记或写入不计入教学配图完成数。用已有代表页核对实际阅读顺序：缩看时首先注意到什么，正常大小下能否看清观察对象、找到对应文字或操作入口。若装饰先于内容被看到、正文图片被挤小或图案从卡缝中露出，优先调整或移去装饰。封面样本同时看题字与图片主体是否互相遮挡。仅对明确安排主题矢量装饰的页面，比对候选源稿、写入节点和实际截图；以摄影、图解或文字排版表达主题的页面，按其承诺的图文关系验收。

这次截图只证明所看版本；后续编辑推进 revision 后按现有证据规则保留历史观察，不伪称当前全篇通过。末尾用其余代表页检查内容与新风险，不为重新点亮早期 passed 而补拍；若最终交付需声明这张已修改页的当前视觉通过，则在剩余抽查中复查它。

## 内容核对优先复用回读

按 STORY 核对实际页数、顺序、题干条件、原文、公式、答案及未完成项。复用草稿和已有回读检查固定页脚、页码/总数、重复教材栏是否误入画面，发现时集中删除相关节点并保持必要图注；不为此新增逐页截图。成功写入的 `layoutReadback.summary` 已包含实际回读；完整且无静态异常的内容不机械重读。仅为截断、缺失细节、异常或修复使用 manifest/document/slide/elements 的有界读取；题目和推理要与可靠材料对照，不能只看是否溢出。

按 STORY 的逐页载体选择核对所有 HTML 活动是否实际插入、必要教学图是否落实；复用已有插入和验证回执，并确认选中的 assetId 实际用于相应页面，不把本地 HTML 文件、原生动画或装饰背景当作替代。汇总实际 HTML 页码与占比、已配置原生动画页码、缺失主图页码，与原计划对照；统计不触发新增截图或为凑比例改页。发现遗漏时集中补齐，无法完成则保留具体未完成项，不能以静态页数齐全宣称整套完成。

对照原 STORY 中每页的具体效果与推进顺序，按 [动画回执规则](animations.md#失败撤销与交付) 核对动画或过渡，明确静态的页无需动画。复用成功配置回执，缺失、不确定或修复后需要细节才定向读取；区分漏提交、notApplied 与 unknown，未落实项保留在当前未完成清单。不得事后把遗漏动画改记为静态、删去活动或配图计划来宣称完成。静态截图不能验证播放或点击推进，不为验证动画反复截图或尝试不存在的放映动作。

## 默认少量视觉抽查

先结合 STORY 与已有回读核对教学内容和可读性，不为字数、填充率、轻微边距或显式小字号提示增加返工。`FONT_BELOW_RECOMMENDED` 表示已保留明确指定的字号，沿用本次代表页抽查判断，不单独触发重试、补拍或全篇重排。复用草稿检查强调是否对应教学重点、有无整段全粗或探究答案提前突出。既有样本同时检查第一焦点、图文关系与 DESIGN 的标题、背景和配色是否落实；密集页兼查富文本、上下标和句子连续性。风格承诺缺失与教学标注遗漏要集中修正；已有完整风格下的色彩或装饰偏好记建议，不另加审美评分调用。

全程通常选 2–3 张高风险或代表页（含前置校准），小课件可更少：末尾优先内容最密页、重点页或新出现的教学例外，复杂公式/坐标图风险可由同一页兼任。各学科图文页兼查教学图、配色、标签和背景；HTML 入口页也可在同一范围内抽查。封面不是必拍项，同一版式不因换标题逐页重拍。先处理已明确的阻断问题，再集中获取末尾样本。

一次取得选定页截图，显式输出图片，结束 codemode。后续模型请求实际看到图片后，先提交这一批的全部观察，再进行任何编辑；通过用 `verdict:"passed"`，有问题用 `"needs-repair"`，不写 `"pass"`。若样本无具体问题，内容及已规划的动画配置核对也完成，即可交付；有未完成项时如实说明范围。不要为了凑满页数或覆盖率继续抓图。已有总览可辅助检查节奏，不通过新增逐页截图制作总览，也不把总览当作未看页面的可读性证据。

有具体问题时，看到截图后的同一次 codemode 先提交这一批全部观察，再顺序读取需修页面并返回所需元素 ID、文字、边界及当前版本；保存完整读取结果供下一轮修复，不先只读一页并截断，再重新读取两页。下一轮集中提交独立补丁，完成所有修改后集中复查。按页查 `query:{kind:"slide",slideId}`；`elements` 用于已知 elementIds，须按实际声明提供 view，不能写成 `{kind:"elements",slideId}`。已读工具声明足够时不重复 describe，更不能把声明转成 String 后截断为 `[object Object]`。

只复查问题页及直接受影响页。只有发现跨页共性缺陷、新增高风险版式或用户明确要求，才扩大抽查，并简要说明理由；不自动转成全篇截图。文字已回读一致且未改变布局时不额外抓图。轻微装饰偏好记 advisories，不无限返工；内容缺失、错误或不可读的问题必须修复，无法修复则如实报告。

默认只进行一轮合并修正与复查。标点孤行、少量留白或高亮偏好在不影响理解时记 advisories，不逐字换行后反复截图。复查仍有缺字、遮挡或不可读时，最多再定向修复一轮；仍未解决则说明具体缺口，不进入无限审美循环。截图报 SLIDE_NOT_FOUND 或保存 ID 无法解析时，先刷新 manifest 核对当前页身份，不猜 ID、不重建已成功页面。

轻微画布出血由生成和审阅的统一规则记录为 advisories；不将提示当作新的全篇返工理由。集中修复时一次收集所有样本的问题及真实元素 ID，合并互不依赖的 setText/setRichText/setBounds/setStyle 后定向回读一次。先完成全部修复批次（包括其他页面、动画和空白页处理），再取需要复查的样本截图；看到后直接提交，期间不再插入编辑。任意页面的编辑都会推进整份文档 revision，尚未提交的其他页面截图也会失效。不要交替执行“改一段、读整页、再改一段、重新截图”，也不要把早期截图积攒到全部修改结束后才提交。原文或公式确有错误仍须修正，不能为省轮次省略内容核对。

## 证据只覆盖实际检查的页

截图直接指定真实 slideId，无需先 gotoSlide。`images` 显式输出后，必须在后续模型请求实际收到且成功返回，才可提交对应 `reviewEvidence.evidenceId`；同一段代码内截图后立即提交不能通过。每张图分别关联 slideId、evidenceId 与业务 operationId，未投递或无法唯一关联的图片不能认领为已看过。

```javascript
const reply = await tools.courseware_read({
	coursewareId: "真实课件ID",
	query: { kind: "screenshot", slideId: "选定的抽查页ID" },
});
image(reply.images[0]);
// 保存 reply.reviewEvidence；结束本次调用，实际看到图片后再提交观察。
```

后续请求只给已经看过的页面提交 `query:{kind:"review",action:"submit",slideId,evidenceId,verdict,observations:{content,layout,teachingVisual},advisories:[]}`，有提示则填写实际 advisories。没有截图的页面保持未视觉审阅，不为“补齐”而提交静态观察冒充视觉通过。

`review/status` 用于查询已有证据，不是每批修复和交付的必经步骤；已知成功编辑后它可能触发 Host 后台截图以核对旧证据。只在需要复用旧结论或全面验收时调用，不能为减少模型图片而把全篇抓图转移到后台。pending/stale 表示覆盖或版本状态，不等于内容错误，不要求自动补拍全部页面。

编辑使旧证据失效；不自行沿用旧 evidenceId 到新版本。需要声明当前视觉通过的已变更页，取得新截图并实际审阅；未变更页面只有运行时按内容指纹与截图摘要证明相同才可复用。revalidation 为 partial 时，仅在需要这些旧结论时继续 review/status；否则保留未完成范围，不循环等待全页通过。未知写入先核对实际文档，不能重放写入。

## 简短交付

最终交付列出 EN 课件，以及本次已生成的完整教学设计／教案，沿用各自已有的成果入口。过程文件按主 Skill 的分类保留，需要时只提供普通预览链接，不列为最终产物。教学设计／教案已交付而课件尚未完成时，保留该成果并明确课件的未完成事项，不能将整项任务报为完成。

复用已有进度和回执，给出 EN 课件入口、实际页数、HTML 活动页码/占比、已配置原生动画页码和未完成事项；让教师知道哪些页可操作、哪些页可点击推进。通常一段结果加简短检查范围即可，无需逐页复述教案或在末尾给过程文件补写一份重复报告。补充一句实际采用的个人规范范围、关键例外和未验证项；涉及专业图时简述实际专业技能、已接入范围与受阻/替代项，区分静态专业产物与页面动态实现，不逐图补发过程成果卡；有规范文件缺失时明确「仅依已确认主题规则制作，完整规范尚未取得」，不能写成完整承接。说明“内容已核对；视觉抽查第 X/Y/Z 页；其余页未逐页截图检查”，不能将抽查通过写成全篇视觉通过。分别说明动画配置、真实播放、保存/云端重开是否有证据；未验证的维度如实保留。用户要求全面验收但未完成时明确缺口，不能按默认抽查口径冒充完成。

箭头与括号在既有代表页抽查内检查：箭头方向是否符合关系、是否穿过正文、虚实线含义是否明确、归纳范围是否准确。原生元数据回读只能确认结构，不能代替这些视觉判断；无需逐图形截图。

## 互动页验收

互动页在插入/更新前执行 [核心操作、反馈与重置断言](interactive.md)。成功回执中的 html.verification 只表示隔离主路径通过，不表示真实托管打开、演示或云端重开通过。沿用全篇少量代表截图，不对每步互动追加截图。真实桌面打开/关闭、重开复位与同步状态分开说明。
