# 视觉层级与密度

制作前与 design.md 一起读取。以下用于安排上屏内容和阅读顺序，不形成新的生成重试或交付门槛。尺寸按 1280×720 逻辑单位计，其他画布等比换算。

## 上屏内容

一页聚焦一个教学任务，保留完成任务必需的原文、题设、数据、关键推理与结论。讲稿、重复解释和扩展背景无需全部上屏；原文精读和完整题目不得为简洁删改条件。信息超量时优先重组主辅关系、按语义分步呈现或合理拆页，并遵守用户页数要求，不能靠缩小正文字号塞满。

不设置单页或单卡最低字数、容器填充率、留白占比与配色面积配额，不计算这些比例，也不逐页编写豁免说明。内容短而任务完整时，使用随内容高度的区域；朗读、观察、推导和作答的留白有实际用途。

## 设计参考

| 对象     | 安排方式                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 第一焦点 | 学生先看到本页的关键问题、证据图、核心引句或重要结果；通过尺度、位置和对比突出，不能只放大页标题                                                        |
| 图文关系 | 图解与解释就近对应，原文与批注按段关联，步骤与依据对齐；长短不同的材料用主辅分区，同维比较才优先等宽卡片                                                |
| 内容容器 | 高度随内容，组内靠近、组间拉开；先用对齐与间距表达关系，必要时再加浅底、侧线或边框                                                                      |
| 主图     | 承担观察或推理任务时给予主要空间，让关键特征与标注可读；角饰、色块和空框不能替代教学主视觉                                                              |
| 色彩     | 所有学科都用主色、辅助色、点睛色与深浅层次丰富画面，保持文字与背景对比；本套复用 DESIGN，新的课件重新按主题确定方向                                     |
| 背景装饰 | 适合的正文页延续选定的纹理、形态或背景分区，读写密集的页面可用净底。图案使用现有余白，教学主图与作答区域优先                                                |
| 字体     | 优先继承主题字级；正文自动缩字最低24，bright及低年级最低28，caption默认16用于必要来源与图注；显式偏小字号只提示，沿用既有抽查；标题、正文、提示保持层级 |
| 全篇节奏 | 围绕导入、观察、推理、练习和归纳安排主次；避免连续用相同密集卡片承载不同任务，同题推导与对照可保持同构                                                  |

普通内容页可从标题区0–120、正文延伸至底部安全边距，左右边距60–80起步；不设页脚区，不显示页码/总页数。上下内边距计入分区，不重复扣减。DESIGN 统一确定页框，封面和重点页可调整。文字实际高度与空间预算遵循 [布局](layout.md#调用前检查)，分区起点不保证内容一定放得下。

## 制作与检查

按 [STORY 逐页规划](workflow.md#story-与-design) 简记教学任务、载体与互动判定、具体动画、图文关系及素材来源；共用视觉规格只写一次 DESIGN，不为每页重做设计表。

当前批次写入前，用已有草稿检查一次内容与阅读顺序。缺少必要材料时补齐可靠来源；内容完整但显空时，优先扩大有意义的主图或缩小空容器。开放探究不提前露出答案，只修改当前页相关节点，不重写整批。

全程默认抽查2–3张代表或高风险页，其中一张普通正文前移到首批校准，避免同一风格缺口扩散；其余留到完成后。检查主次、图文关系、可读性和风格兑现；已承诺的背景、重点标注或配色缺失要修正，轻微间距和偏好差异不触发重做。具体轮次与证据见 [检查与交付](review.md)，不增加逐页截图、像素扫描或独立评审调用。
