# 主题视觉设计

## 个人样式约束

先落实 [个人规范](personal-style.md)，再补通用视觉细节。DESIGN 必须区分「已确认且适用、需稳定保持」与「本课自由补充」：前者包括真实规范中的标题/问题/答案/图示角色、栏目位置、页型关系、颜色语义与显示时机，后者可包括未限定的装饰和背景。没有实测字号、色值时不伪造精确参数，本课采用值明确为实现选择，不冒充原作测量。用户已有固定栏目时保留其名称与位置，具体问题标题在该体系中变化；固定图的变式只改变约定的条件和标记。

将上述要求落实到本课共享 CoursewareDesignSpec 与纯函数；不能仅套通用配色。不同语义角色需要不同颜色时使用当前 API 支持的样式或 runs，不把所有答案、术语和变化项一律归为同一个 accent。HTML 沿用同源变量并保留相同的角色关系和答案位置。手记报告的包装主题不等于教师的课件风格。以下关于风格变化、自由构图和氛围装饰的默认建议，不覆盖适用已确认的个人规则。

默认目标是教学内容完整、主次明确、配色有层次、背景有主题氛围、图文有对应关系。以下适用于所有学科和主题：同一套课件保持统一，不同课件主动变化视觉方向；用户指定极简、品牌规范或沿用已有风格时遵守其要求。按 [视觉层级与密度](visual-rules.md) 组织上屏内容，不增加规划文件、风格确认或逐页审美循环。

## 主题与页框

先根据当前课题、学生年龄、内容关系和用户偏好确定视觉方向。运行时 [主题 token](themes.md) 提供可用配色和字体基线，不绑定学科、页型或装饰套路；模型自主设计素材语言和构图。接口与间距边界见 [布局](layout.md)，默认不读取内置视觉样例。

画布 1280×720。在画布内保留足够安全边距，自行安排标题、正文、图片与必要图注，在 DESIGN 中明确统一参数。全篇使用一致的对齐原则和文字层级，封面、正文与重点页可有不同构图。所选外边距保持稳定，自动适配留给内容区；不得为容纳文字把安全边距挤没。

所有页面不绘制固定页脚、页码/总页数、底部教材版本或课程署名栏、装饰性进度条，也不预留空的页脚带。不将这些内容迁移到页眉或角标；STORY 与工具中的 pageKey、页序、总数继续用于编排，不转成上屏文字。教材定位按需要在封面说明一次，必要来源与图注靠近对应材料，完整出处放备注或交付说明。标题使用具体问题或内容，去掉无意义的英文眉题、章节序号、重复套话和口号；真实题号、操作步骤及互动导航保留。

## 整套视觉规格与原生复用

选定视觉方向后，在 DESIGN 一次确定配色语义、背景与装饰语言、页底与内容底的对比、标题标记、字体层级、间距、图片媒介及安全边距。写清选项中承诺的可见特征如何进入普通正文页，例如纸张材质与侧批、摄影剪影与冷暖标记、几何切面与变量配色；不能只写风格名称。封面、正文、重点页可以有不同背景强度与深浅变化，统一来自颜色含义、字体搭配和装饰语言，不自行规定全篇同底色或同布局。对线稿、剪影或插画方向，写清可辨认的对象轮廓、绘制手法、构图与文字留白，以及哪个教学环节需要完整图、局部图或净底。在安排使用该图稿的页面延续所选线条和姿态；不同课题可以分别采用山势的连续层叠、花枝的自然分叉或鼓绸的运动曲线，具体图稿随课题创作。共享结构用于本套课件内复用；新课件重新按课题确定方向，不自动沿用上次的整套皮肤。

首批将 DESIGN 的颜色、文字角色、强调方式和可复用背景保存为一份 `CoursewareDesignSpec`，用 [createCoursewareDesign](components.md#课件级风格与语义富文本) 对原始 page 调用 apply，再暂存完整参数和写入；公共组件与手写节点都由同一配色展开，HTML 活动沿用其 cssVariables。标题、批注、步骤与结论的具体构图用少量本课纯函数复用，不预建固定页型库。显式具体颜色会保留，只在有意例外时使用，避免手写旧色值覆盖新风格。共享 spec 与结构随现有草稿保存，后续读取复用，不依赖跨 codemode 全局变量，也不增加规划文件或模板生产阶段。

用户给出 HTML 课件、模板或截图时，先提取其视觉关系，再映射为原生元素：标题线与色带用 shape，段落重点用 runs，图文分栏与步骤行用 flex，局部叠放用 stack。背景、标签和正文保持明确对比，保留参考中的视觉层级和主题装饰；装饰可沿页边、背景或大图展开，正文区保持清楚。无需复刻浏览器像素坐标、读取整套模板库或给每页另做 HTML 稿。仅有缩略图时不猜精确字号与色值，以用户方向和实际原生测量落实。

可按内容采用以下组织方式，不与学科绑定，也不要求整套使用同一构图：

| 内容关系       | 视觉组织与原生落点                                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 原文与证据批注 | 原文为主，批注贴近对应词句。用位置、留白和富文本强调关联证据与解释；需要独立引文区时可用 QuotePanel                              |
| 图解与推理     | 给准确图示主要空间，旁侧按步骤对齐条件、推导和结论；浅色问题带与局部强调区分任务和答案。使用 diagram/image 与 flex，讲解页按教学节奏揭示答案 |
| 分类与比较     | 行列共享比较维度，标签、证据与结论沿固定阅读方向对齐；用原生文字、分隔线和浅底组织，避免所有内容都变成同权重卡片                             |
| 情境与重点问题 | 主图或核心引句形成焦点，简短任务贴近观察对象；封面与重点页允许大图、非对称布局和有用途的留白，内容页沿用相同字体与色彩语义                   |

同一内容关系可以采用多种视觉语言，例如阅读批注可用纸感拼贴或清透插画，图解推演可用彩色几何或图鉴式编排；这不是学科与风格的固定映射。定制色只在共享定义中保存一份，通过支持的节点颜色属性使用，不发明新的 theme 值。

## 通用配色背景与教学配图

所有学科都按课题确定主色、辅助色、点睛色和深浅层次，参考 [通用配色与风格变化](themes.md#通用配色与风格变化)。配色作用于背景、标题、图像和教学标注，不只改变标题颜色。人物、概念、对象或关键变化使用有区分度的颜色并配标签，同一含义跨原生页与 HTML 活动保持一致。封面、转场与重点页可用较大的色块、主题图或深浅对比；普通内容页保留同一视觉语言，正文区保持稳定对比。

让学生先看到本页要观察、比较或朗读的对象。讲《安塞腰鼓》的“静—动—静”，可让前后的短句留出停顿，中段给密集的动作和声音更宽的行幅；讲一元二次方程，花园图与对应的面积关系就近放置，后续推导沿等号对齐。分组、行宽和间距随实际内容决定。

封面可采用搜到的照片或生成的情境插画，按[素材准备与复用](#素材准备与复用)获取。先看图中人物、动作或观察对象的位置，再决定满幅留白叠题或图文分区；底图复杂就把标题放在独立净色区域。生图时写清主体方向与标题留白，课名用原生文字排入。需要真实记录时遵循原有来源要求。纯文字或公式构图也可自成封面。

正文先放足尺寸的教学图、原文、图注和操作区。装饰只可用现有余白，不预留装饰栏，不缩小主图或字号为纹样腾位；若遮住观察细节、穿过卡缝或比教学重点更抢眼，就省去该页装饰。照片或插画本身已表达主题时，可从画面取色用于标题与标注。

在已有 STORY 的“第一焦点与图文关系”和“教学素材与来源”里逐页确定需要的图，不另建素材规划阶段。各学科在情境、精读、概念、建模、实验和迁移中主动寻找可观察、可比较、可解释的对象，用图片承担教学内容；配图不能只停留在封面或全篇反复用同一张场景图。若连续多页本可用图帮助理解却只有文字，在规划时补入对应的观察图、对照图或过程图。装饰背景、角饰不计作这些教学主图；完整阅读、定义与纯演算无需硬凑图片。

| 用途       | 选图与实现                                                                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 情境与观察 | 优先搜索与材料相符的自然、人物、生活场景、物体或装置照片与插画；真实史料、实验记录与证据用可核验材料，文字与数值留给原生标注                                                   |
| 理解与推理 | 文本意象、人物关系、事件顺序、概念分类或实验过程用对应图像与图解帮助理解；简单面积拼补按数值关系构造原生形状，纯数学精确曲线、坐标与几何关系用 diagram；专业学科图按接入规则生成，不用 AI 图片代替精确关系 |
| 探索与反馈 | 将核心模型放进 HTML 活动，操作引起图形、参数或判断反馈变化；原生讲解页保留必要的模型图，不把全套图像都藏在互动弹层里                                                           |

例如“配方法四步”可让面积拼补图与代数步骤并排：原有面积、重新分配的部分、补入的角块分别用蓝、青绿、橙，公式中对应项沿用相同颜色和标签。面积模型明确非负边长等假设，不能用面积图排除代数中的负根。步骤文字概括操作与依据，关键变化由图说明；HTML 活动再让学生实际拼补并检验结果。

素材按批获取，相同对象复用已登记图片或图解源，不为换页重复生图。普通素材按[检索与生图兜底](#素材准备与复用)补齐。已指定专业技能生成的图按 [学科接入](subject-integration.md) 的受阻与确认规则处理，保留原规划中的核心配图需求。配色、配图与互动都在现有制作批次和抽查中落实，不增加逐页截图或额外美化循环。

## 内容显空时先查内容，再改空间

普通讲解页通常包括核心内容、支撑材料和学习动作：文学精读有原文与对应批注，数学概念有条件与准确图示，实验有变量与观察任务，练习有完整题干与实际作答区。并非每页都必须包含所有项目，朗读页、重点问题页、观察页可围绕一个明确任务展开。

调整顺序：

1. 检查本页任务必需的原文、证据、例子、图示或学习动作是否缺失；只用已核对材料补齐。原创例题标明其性质并验证正确性，不添加未经核实的引句、数据或重复结论。
2. 内容完整仍显空时，扩大有教学价值的主图、引文或关系图，调整主辅比例，取消无意义的满高卡片。先定第一焦点的实际文字/图像尺度，再分配剩余宽度；grow 只会扩大容器，不会放大其中的短诗、公式或图片主体。辅助批注贴近对应内容，避免两个小文字组分居画布两端。背景可铺满区域，文字容器优先随内容高度。
3. 只有同维比较才优先使用等宽、等高卡片；无对照关系的长短内容用主辅分区。独立意义不足的页可与相邻内容合并，但须遵守用户页数要求与教学节奏，固定页数时在本页重组。
4. 保留服务朗读、观察、推导和作答的留白，在 STORY 中简记用途。不要为填空提前暴露探究答案，或把作答区塞满装饰。

## 从内容关系生成构图

先决定学生本页要看清什么、比较什么或完成什么，再组织材料的位置、尺度和阅读顺序。模型自主设计分区与对齐，不从预设页型清单选版，不照搬内置 TSX 或预览。

统一全篇的字体层级、颜色用途与素材媒介；标题位置、主图尺度、正文分区和留白随内容变化。封面、正文与重点页可采用不同外框，不强制标题始终置顶、结论始终放底部，也不要求每页有卡片或角饰。同类内容可沿用有效构图，不为求变破坏阅读。

用户提供或明确指定参考时才分析该参考；没有参考时直接创作，不先搜索模板库。自由度不改变内容正确性、文字可读性和真实 EN 能力边界。

## 背景与装饰方案

在本课 DESIGN.md 用一个独立小节规划背景与装饰。先写默认页底，再写本课要呈现的场景、纹理、形态或深浅分区，以及它在封面和适合的正文页如何变化。记录可复用图稿或背景图片的来源、适用的页型或 pageKey、位置和避让区。用户已选净底方向、个人版式或参考模板时，按约定规划。

普通正文默认沿用本课选定的背景图稿。相邻的讲解、对照与归纳页可共用同一个低对比变体，保留读者能辨认的轮廓。若方向用航线弧线表达连接，可在讲“如何联系”的页面借右侧余白延续弧线；纸偶风格可在独立的叙事区边缘延续纸片剪裁的轮廓。用低对比浅纹、局部主题图形或深浅分区承托内容，视课题与版式选择。标题短线、卡片底和教学高亮用于组织内容，主题图稿仍按选定方向落实。引用与分隔线随对应内容放置。共享装饰按适用页面使用，避免全套套用同一条页边长线或通用角点。

按图片在该页的用途归档。以《荷花》为例，封面用荷塘全景引入课题，第 2 页用同一张图观察荷叶的疏密，两次用途都记在 STORY，复用同一份图片。DESIGN 的方案可以写成“默认淡米底；封面题字放在主图左侧净色区；转场页右下用荷叶线稿；观察页和互动页用净底”。如果荷塘影像仅作氛围底图，就在 DESIGN 记录其来源与裁切位置。搜图、生图和满幅铺图都适用这一判断；同一资产跨用途时引用已有来源。

原生页将教学图片、证据标注和关系箭头随对应内容放在页面内。共用装饰放进 `spec.backgroundElements`，用 `apply` 放到规划中的页面。净底或独立构图页可显式关闭共享装饰。需要变体时从同一 spec 派生背景节点并调整位置或强度。HTML 页按相同规划把背景层放在文字、反馈和控件下方。

图案优先放在完整余白内。底纹可以铺在净色分区后方，保持图文轮廓和读写区域清楚。密集页优先保留相同图案的局部，给教学图、正文和控件留净区。需要整页净底时按页在 DESIGN 中记为例外。共用图稿可用[主题矢量图稿](vector-graphics.md#主题矢量图稿)或登记图片。

线、带、圆点、标签优先用 EN 原生形状和文字，背景与强调底先输出，正文后输出。装饰使用独立稳定 key，教学动画仅绑定明确指定的内容节点。复杂纹理和主题角饰使用已登记的局部图片，不栅格化整页；没有素材时用有意图的线条、色块和排版，不留占位框冒充完成。

当前可用矩形、圆角矩形、椭圆、形状填色/描边/整体透明度及 stack 叠放。分隔优先用明确的窄矩形，避免依赖未输出的容器描边。渐变、复杂阴影、旋转和艺术蒙版不是任意 CSS 能力；需要时使用登记素材。图片支持style.opacity和cover归一化focus裁切；没有艺术蒙版参数。通用线稿、曲线和关系图可用[矢量图解](vector-graphics.md)，标签保持原生文字。

## 配色、字体与层级

主题色通过语义 token 或本课共享定制色使用：正文、次要文字、强调文字、装饰和分隔各司其职。默认强调可用 `$accent`，装饰用 `$decorative`，分隔用 `$line`；`$onAccent` 只用于 `$accent` 实色背景；`$accentSoft` 搭配 `$ink` 或 `$accent` 文字。色块、纹理和图片共同形成背景层次，正文区域用清晰的明暗对比保证阅读；定制深色底时显式选择可读前景，不沿用深色正文。不得把浅金等装饰色自动用作教学正文。

普通正文优先主题默认字级，自动适配下限与各角色档位见[主题与自动调整](layout.md#主题与自动调整)；低年级可用 `bodyMinimum:28` 或更高提高自动缩字下限。必要来源和图注用 caption 默认16。封面或章节展示标题可显式设为 60–96，核心数字可更大；显式字号只锁定本节点，不阻止同组其他正文适配。显式低于角色推荐值只返回可读性提示，沿用既有抽查，不因此重试整页。复杂公式分行，不缩成脚注。

字体先继承主题和文字角色，再按实际环境解析可用字体；显式 fontFamily 只接受单一字体名，不写 CSS 字体栈。标题和原文可以配对，实际字体及回退以工具结果和原生截图为准。同段关键词优先用 `paragraphs/runs` 富文本强调，批注、解释和操作提示可独立节点；不把每个高亮词拆成无法自然换行的文字框。检查中英文混排、标点避头尾、标题语义换行与孤行，避免仅凭几何不溢出认定排版合格。

## 正文富文本与重点标注

讲解、精读、概念与题目页有明确教学重点时，先在 STORY 的必要内容中简记需突出什么以及何时呈现，再用 design.paragraph 的语义强调或原生 runs 落实，不另做高亮清单。概念、条件、证据、变化、结论适用于各学科；诗句的节奏与正音、推导的变化项、实验的变量与观察、史料的证据、外语的句型都按实际教学任务处理。只创建 paragraphs 或整段设置统一字体不算重点标注。开放探究的答案后揭示，不能因此把朗读节奏、已知条件等必要提示也全部取消；完整原文和测评按任务保留纯文本，不机械凑高亮。

- 常规正文保留正常字重与`$ink`；关键概念/条件用`bold:true`，本页最核心的短语可再加`color:"$accent"`。全篇同一种强调含义使用同一种样式，不能只靠颜色区分正误或概念类别。
- 每段通常选择1–2处短语，强调正文约10–20%作为起点，按语义调整；避免整句整段全粗、每句一种颜色、每个名词都突出。该比例是设计建议，不是写入门禁，不新增计数工具。
- 长段按原有语义分组，必要时加简短小标题；同一段内部用runs连续排版，段间通过spaceAfter拉开，行距优先1.15–1.3并结合实际高度。小标题、关键词和任务提示形成不同层级，不用大量等大卡片代替层级，也不为突出关键词破坏句子或删减正文。
- 操作提示与背景知识分开，任务动词可加粗，必要时用浅色结论带；任务正文优先继承body字级，不用灰色caption弱化学生必须阅读的内容。必要来源与图注才使用caption。

接口见[布局中的富文本](layout.md)。run支持bold、italic、color、fontFamily，以及backgroundColor、underline、baseline。关键词优先加粗；需要从连续原文中标出证据时使用浅色backgroundColor（优先主题$accentSoft并保留$ink文字），任务条件可用underline。不要在同一短语机械叠加加粗、变色、底色和下划线；中文重点通常不使用斜体。上下标baseline仅表达指数、单位、化学式等真实语义，不用于缩小普通正文。

段内底色和下划线由原生文字引擎随run换行，不逐词叠背景矩形，也不拆成独立文字框。高亮范围只覆盖关键短语；取消强调时清除对应属性。字符串仍不解析Markdown或HTML。

## 素材准备与复用

教学素材按 STORY 中的用途优先复用本次任务已确认图片，再按批搜图并看图选用；专业学科图先执行 [学科专业技能接入](subject-integration.md)，物理静态图由 seewo-physics-illustration 实际生成、检查、登记后插入，不走普通搜图/生图替代；纯数学精确图用 diagram，简单原生图形无需先搜图。普通配图优先检索；用户明确要求直接生图时按其要求准备。允许用 AI 示意的情境图、观察图和叙事插画可在检索未命中时用生图兜底。真实照片、史料和实验记录使用可核验来源。先确定素材角色、关键特征与目标比例；主图需要足够尺度让学生看清观察对象，全篇保持媒介与角色一致。

按当前工具声明调用，不猜参数：

1. 首批准备当前页面需要的教学主图，后续随批次获取。DESIGN 如需另取背景图片，以背景用途检索或生图，将来源记在对应的背景方案中。用 `tools.images_search({queries:[...],count:8,purpose:"本批图片用途"})` 合并最多 5 个不同素材需求，必要时加 `aspect_ratio`；避免同一需求换几种近义词重复请求，也不一页一次串行搜图。查询描述具体对象、场景和关键特征，避免过度限定颜色导致搜不到图，视觉一致性可用现有裁切、标注与主题底色完成。
2. 在首次搜索的同一次 codemode 中，用 `image(candidate.preview)` 输出相关候选的可用预览，并保存 assetId、path、query 等小型索引；只打印该索引及 issues，不序列化含 preview 的完整返回值或截断其 JSON。结束调用，后续模型请求实际看图后，再调用 `tools.images_select({assetIds:[...],purpose:"实际采用用途"})` 选择所需素材，并将小型结果对应到具体 pageKey 与观察对象。不能用查询词、返回顺序或选图时统一填写的 purpose 代替实际看图；避免将“荷叶密集”图误用为花朵特写。候选预览仅供模型选图，不将全部候选登记为用户最终成果。
3. 保留合适候选，只针对仍缺图的需求补搜一轮。空结果、实际看图发现主体无关或缺少教学所需特征、只有重复图且不适合本页时，用更具体简短的对象与场景词补搜。仅有 `images_create` 兼容入口时，检索用 `mode:"search"`。复用本轮已有搜图和看图结果，恢复任务时沿用已完成的轮次。
4. 首轮和针对性补搜都未取得合适图片，或已确认检索能力不可用时，直接为仍缺图的导入、观察或重点讲解页生成适合用 AI 示意的教学插画。生图兜底是课件制作的默认步骤，无需调用 `ask_user`。有明确的禁用生图、只搜图或真实素材要求时，按用户要求处理。调用 `tools.images_create`，指定 `mode:"generate"`、适合图框的 `aspect_ratio` 和本页 `purpose`。提示写明教学对象、关键可见细节、场景、构图及全套课件的媒介与配色，留出原生文字位置。
5. 回执有预览时用 `image(reply.preview)` 输出生成图，否则读取回执的真实 `path`。实际看图核对主体、教学细节和裁切效果，合格后用回执的 `coursewareSource` 插入 EN 原生图节点，或按 [互动页图片合同](interactive.md#教学与画面) 将登记的 `assetId` 嵌入 HTML。按页记录实际插入的 assetId 和来源，教学文字保留为页面文字。生图受用户要求限制、工具不可用或生成结果不合格时，能准确表达本意的页面可用原生图解，仍缺的教学主图记明页码及原因。生成超时、中断或返回 `IMAGE_GENERATION_UNCERTAIN` 时先查已有回执和资产，保留未确认状态，避免重复提交。

搜索返回元数据、打印截断或忘记输出预览，都不表示搜索失败，不因此重跑同一组查询。有真实 path 时可用现有图片读取能力补看所需候选；尚无可用读取方式时说明缺口，调整检索或换可用来源取得能实际查看的候选。预览直接输出，不把 base64 存入 store。

```javascript
const result = await tools.images_search({ queries: ["本课需要的具体观察对象与场景"], count: 8 });
const index = result.candidates.map((c) => ({ assetId: c.assetId, path: c.path, query: c.query }));
store("cw:image-candidates", index);
for (const candidate of result.candidates) {
	if (candidate.preview) image(candidate.preview);
}
text({ candidates: index, issues: result.issues });
// 正常结束；实际看到候选后再选择，不能为补回这些结果重复搜索。
```

同一观察对象和连续任务复用已登记 assetId；需要比较不同对象或情境时搜索相应图片，不能靠重复一张图增加配图数量。仅准备本课需要的素材，不读取内置样例源码和预览。作者头像须核实身份，不采用带“AI 生成”标识的图片；其他场景不因该标识单独拒绝已有素材。来源或 AI 标识默认保留，图注沿用 DESIGN；不为装饰细节开启裁图、像素扫描或水印定位脚本。确实遮挡主体时调整图框或选用另一张素材。

真实史料和实验数据用可核验材料；精确数学图使用 [diagram 确定性绘图](math-visuals.md)，不以搜到的相似示意或 AI 插画冒充精确关系，也不用原生短线拼曲线。生活情境、实验场景与封面优先搜到合适照片或插画，理科不必一律画成坐标图。艺术画面不标伪精确数值。图片通过产品工具登记获得真实 assetId，不传猜测 ID、文件路径或远端 URL；教学正文留给 EN 原生文本，后续可编辑。

首批正文校准及全篇完成后的集中检查按 [检查与交付](review.md) 执行；已有缩略图可辅助看节奏，不为总览逐页抓图。抽查只证明实际所看页面，示例好看、布局回执成功或局部近似渲染不能证明全篇视觉通过。

## 关系箭头与归纳标注

推进或因果关系用单向箭头，互相比较或联系用双向箭头；归纳同组证据用方括号或花括号。关键判断可用小菱形、注意事项可用小三角形，并配可读文字。仅在教学关系需要时加入，避免每段文字都框住、连接或贴标记。标注线应有明确起止与含义，使用统一强调色和描边粗细，避开正文与图片主体。原生API及当前边界见[原生箭头与标注图形](layout.md#原生箭头与标注图形)。
