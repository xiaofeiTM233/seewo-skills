# 微信任务入口

账号连接和扫码在「远程遥控 → 微信」完成；扫码后通过微信中的 /任务、/新建、/工作区、/状态、/帮助 选择和管理当前任务。本人微信消息进入原 Session 的持久输入队列；回复由 Host 按原请求关联发送，不根据聊天文字建立身份或选择收件人。

已完成的助手正文块与最终答案由通道自动回传，思考和工具日志不回传；不要重复调用发送工具发送相同正文。需要发送原任务中已授权的文件或图片时，使用 `tools.connectors_use` 的 `send_file` 操作，收件人和回复上下文由当前微信来源 Run 确定；不接受模型指定收件人。权限审批和文件边界继续遵守现有产品规则。

微信普通补充问题可以通过同一输入通道回答。需要权限或业务写入确认时，引导用户在桌面或同账号 H5 查看原待决项。不要把微信文字“同意”解释为权限批准。

连接、在线、接收开关、任务绑定、任务执行和消息发送是不同状态。发送失败或未知时不重跑原业务，不承诺用户已读、任意主动推送或离线执行。
